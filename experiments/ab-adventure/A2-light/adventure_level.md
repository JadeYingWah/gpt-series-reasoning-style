# 星际逃生 - 文本冒险游戏关卡设计文档

> **类型**：分支叙事（Branching Narrative）+ 探索地图混合
> **参考**：2026年互动叙事设计最佳实践（有意义的选择、收敛点、延迟后果、状态追踪）
> **预计游玩时长**：15-20分钟
> **结局数量**：4个（1好+2中+1坏）

---

## 一、设计概述

### 1.1 核心概念
你是空间站"奥德赛号"的首席工程师。一次陨石撞击损坏了主电源和生命维持系统。你必须在氧气耗尽前做出一系列关键决定，决定不仅影响你能否逃生，还影响你能救出多少人。

### 1.2 核心机制
- **氧气计时器**：初始30分钟，每个选择消耗不同时间
- **物品系统**：可拾取关键道具（扳手、手电筒、氧气罐、密码）
- **道德选择**：救自己 vs 救他人，效率 vs 风险
- **延迟后果**：早期选择影响后期可用选项

### 1.3 有意义的选择原则
每个选择必须满足以下至少一项：
- ✅ 改变游戏状态（获得/失去物品、时间、盟友）
- ✅ 揭示新信息
- ✅ 表达角色性格
- ✅ 制造紧张感
- ❌ 纯装饰性选择（"走左边 vs 走右边"但结果相同）已删除

## 二、状态系统

### 2.1 玩家状态
```
oxygen: 30        # 剩余氧气（分钟）
health: 100       # 生命值
inventory: []     # 物品列表
allies_saved: 0   # 救出的人数
knowledge: []     # 获得的信息/密码
```

### 2.2 物品清单
| 物品 | 获取地点 | 用途 |
|---|---|---|
| 扳手 | 控制室工具箱 | 启动发电机、清理碎片 |
| 手电筒 | 控制室工具箱 | 照亮黑暗走廊 |
| 氧气罐 | 医疗舱 | +15分钟氧气 |
| 医疗包 | 医疗舱 | 恢复50生命值 |
| 密码(1987) | 控制室站长桌 | 打开逃生舱 |
| 门禁卡 | 站长身上 | 打开储藏室 |

## 三、场景与分支

### 场景1：控制室（起点）
**描述**：你在警报声中醒来。控制室灯光闪烁，主屏幕显示"氧气泄漏：30分钟"。站长倒在地上，不省人事。

**选择**：
1. **检查站长**（消耗2分钟）→ 获得门禁卡，发现站长还有呼吸
2. **打开工具箱**（消耗1分钟）→ 获得扳手+手电筒
3. **直接冲向走廊**（消耗0分钟）→ 但走廊黑暗，没有手电筒会受伤

**收敛点**：无论选择什么，最终都会进入走廊，但状态不同。

---

### 场景2：主走廊
**描述**：走廊一片漆黑（除非有手电筒）。三个方向：引擎室（左）、医疗舱（右）、逃生舱方向（直走，但被碎片挡住）。

**选择**：
1. **去引擎室**（消耗3分钟）
2. **去医疗舱**（消耗3分钟）
3. **清理碎片**（消耗5分钟，需要扳手）

#### 2a. 引擎室
**描述**：备用发电机在这里，但需要扳手启动。

**选择**：
- 有扳手 → 启动发电机（消耗2分钟）→ 灯光恢复，氧气泄漏减缓（+10分钟氧气）
- 无扳手 → 无法启动，白跑一趟（浪费3分钟）

**延迟后果**：如果启动了发电机，后续场景的描述会提到"灯光恢复"，且医疗舱的设备可以使用。

#### 2b. 医疗舱
**描述**：医疗舱里有医疗包和氧气罐。如果发电机已启动，医疗设备还在运转，可以治疗站长（如果带着站长）。

**选择**：
- 拿氧气罐 → +15分钟氧气
- 拿医疗包 → +50生命值
- 两个都拿 → 消耗额外1分钟

#### 2c. 清理碎片
**描述**：你用扳手清理碎片，打开了通往逃生舱的捷径。

**结果**：跳过场景3，直接进入场景4，但消耗5分钟。

---

### 场景3：居住区（分支点）
**描述**：你经过居住区，听到敲击声。有人还活着！

**选择**：
1. **救人**（消耗8分钟）→ 救出2人，allies_saved=2，但氧气紧张
2. **继续前进**（消耗1分钟）→ 不救人，但保留氧气
3. **留下氧气罐继续**（需要氧气罐，消耗0分钟）→ 给他们氧气罐，allies_saved=1，不消耗额外时间

**道德权重**：这个选择影响结局评价。

---

### 场景4：逃生舱
**描述**：你到达逃生舱。舱门被锁住，需要密码。控制台上有提示："密码=站长生日"。

**选择**：
1. **输入密码**（需要knowledge中有"1987"）→ 舱门打开
2. **回控制室找线索**（消耗4分钟）→ 在站长桌上找到照片，背面写着"1987"
3. **暴力破解**（消耗10分钟，生命值-30）→ 有50%概率成功，失败则触发自毁

## 四、结局系统

### 结局1：完美逃生（好结局）
**条件**：氧气>0，密码正确，allies_saved≥1
**描述**：你带着幸存者成功逃离。回望空间站，你知道自己做了正确的选择。
**评价**：英雄式结局，玩家感到自己的选择有意义

### 结局2：独自逃生（中结局）
**条件**：氧气>0，密码正确，allies_saved=0
**描述**：你独自逃离，但耳边还回响着居住区的敲击声。你活下来了，但能心安吗？
**评价**：道德拷问，鼓励重玩

### 结局3：惊险逃生（中结局）
**条件**：氧气≤5但>0，密码正确
**描述**：你在最后一刻进入逃生舱。氧气面罩戴上的瞬间，你昏了过去。醒来时已经安全了。
**评价**：紧张感拉满

### 结局4：窒息（坏结局）
**条件**：氧气≤0
**描述**：你的视线开始模糊。最后看到的是逃生舱的门，近在咫尺却远在天边。
**评价**：时间管理失败的惩罚

### 结局5：自毁（坏结局）
**条件**：暴力破解失败
**描述**：警报声变成了连续的长鸣。"自毁程序已启动"。一切都结束了。
**评价**：冒险选择的惩罚

## 五、分支流程图

```
控制室
├── 检查站长 → [门禁卡] → 走廊
├── 工具箱 → [扳手+手电] → 走廊
└── 直接走 → [受伤] → 走廊
    ↓
走廊
├── 引擎室 → [有扳手→启动发电机+10氧] / [无扳手→浪费]
├── 医疗舱 → [氧气罐+15氧] / [医疗包+50血]
└── 清理碎片 → [跳过场景3] → 逃生舱
    ↓
居住区（分支点）
├── 救人 → [allies+2, -8氧]
├── 不管 → [allies+0, -1氧]
└── 留氧气罐 → [allies+1, 消耗氧气罐]
    ↓
逃生舱
├── 输入密码 → [需要knowledge] → 结局1/2/3
├── 回去找 → [-4氧, 获得密码] → 结局1/2/3
└── 暴力破解 → [50%成功/失败] → 结局3/5
    ↓
氧气≤0 → 结局4
```

## 六、设计要点

1. **收敛点设计**：场景1的三个选择最终都进入走廊，避免内容指数爆炸
2. **延迟后果**：是否启动发电机影响医疗舱描述和后续可用选项
3. **有意义的选择**：居住区的道德选择影响结局评价
4. **时间压力**：氧气计时器制造紧张感，每个选择都有时间成本
5. **重玩价值**：4个结局+道德选择，鼓励玩家尝试不同路径
6. **物品驱动**：扳手、手电筒、密码等物品解锁不同选项
