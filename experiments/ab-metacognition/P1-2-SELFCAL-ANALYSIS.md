## 三、初步结论（待红队轨补充）

1. **自我校准缺口普遍存在**（10 份中 7 份），无 skill 条件下 100% 出现且幅度最重（唯一的数据损坏类双缺+恒真断言都在无 skill 组）。
2. **skill 条件把缺口率从 100% 压到约 33%**——原则与硬指标在该指标上无显著差异（1/3 vs 1/3；原则组另含 1 例声明矛盾）。这是 skill 价值的又一独立证据线：**它改善的不是「不产生 bug」，而是「知道自己哪里可能错」**。
3. 「声明与实现矛盾」3 例跨条件分布（无 skill 1、硬指标 1、原则 1）——声明质量与条件无关，属普遍风险；锚点 rubric 的 −1.0 矛盾扣分有效捕捉。
4. **最强自校准样本**：T2-34（硬指标）m09 存活自曝→补用例→复杀全过程留痕 + 0 缺口；T3-57（原则）自限「变异体不能证明对第三方缺陷有鉴别力」。两组各有典范。
5. 红队轨待回答：无报告锚定的纯黑盒审查，发现能力与「有报告的判分子」相比如何——若红队发现 ≥ 判分子，说明证据报告可能锚定审查范围（对新审查者是辅助还是干扰）；若 <，说明报告是有效的审查地图。
