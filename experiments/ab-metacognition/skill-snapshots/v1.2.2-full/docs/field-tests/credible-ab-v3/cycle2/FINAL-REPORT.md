## 8. 对 skill 改进决策的建议（回应用户最初诉求）

1. **能力条款不再加码**：交付质量 A=B、诚实两臂都高、M4/范围克制均非 skill 独占——在强底座模型上
   堆能力条款的边际收益不可测。
2. **工程面是真实短板**（本轮实锤）：①部署一致性（BD-01 路径声明错误也是部署面问题）；
   ②**成本闸门**（OB-01：107MB 证据树/2213 文件）；③**副作用隔离**（OB-02 全局 taskkill；运行临时物
   混入交付目录——DIR01 A 的 Chrome profile 占证据树 99%）。
3. **可写进 skill 的三条候选**（源自本轮台账）：
   - 「清理运行环境限定自有 profile/端口，禁止全局杀进程」（OB-02）
   - 「运行临时物不落交付目录，完成后清理」（OB-01）
   - 「收尾清理禁止对对照臂/他人目录执行列目录或读取」（V-01）
4. **有效性证明路径**：本装置（并发 24 臂 + 0-2 尺度 + 补写污染）无法干净估计效应量；若要继续，
   应走小 n、串行隔离、连续尺度、预注册判据的干净实验，而非扩大样本。
