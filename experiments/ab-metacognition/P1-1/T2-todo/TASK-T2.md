# 任务：命令行待办清单（T2）

写一个 Python 命令行待办工具 todo.py，单文件零依赖。

## 功能要求
1. add "标题" —— 新增待办（自增 id、默认未完成、记录创建时间）
2. done <id> —— 标记完成
3. list [--all] —— 列出未完成（默认）或全部（--all），表格对齐输出
4. rm <id> —— 删除
5. 数据存 todos.json（脚本自动创建）

## 边界情况（必须处理）
- 空标题 / 只有空格的标题
- 不存在的 id（done/rm）
- 重复 add 相同标题（允许，id 不同）
- 标题含引号/换行/emoji/超长（500 字符）
- todos.json 损坏或缺失时不得崩溃
- 空库时 list 的友好提示

## 交付要求
- todo.py 单文件
- 完整验证（功能+边界）
- 证据报告
- 验证脚本必须可被第三方独立复算

产物放在指定目录。
