# 品牌视觉规范

## 配色方案

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 | #2563EB | 主按钮、链接、强调 |
| 主色悬停 | #1D4ED8 | 主按钮悬停态 |
| 辅助色 | #7C3AED | 次要操作、标签 |
| 成功色 | #059669 | 成功状态 |
| 警告色 | #D97706 | 警告状态 |
| 错误色 | #DC2626 | 错误状态 |
| 文本主色 | #111827 | 正文、标题 |
| 文本次色 | #6B7280 | 辅助文字 |
| 背景色 | #FFFFFF | 页面背景 |
| 边框色 | #E5E7EB | 边框、分割线 |

## 按钮组件

### 主按钮（默认态）
- 背景：#2563EB
- 文字：#FFFFFF
- 圆角：8px
- 内边距：12px 24px

### 主按钮（悬停态）
- 背景：#1D4ED8
- 文字：#FFFFFF

### 主按钮（禁用态）
- 背景：#1E40AF
- 文字：#FFFFFF
- 不透明度：0.4
