# Test-Bed 1：轻任务双臂对照实验

## 实验设计
6个轻任务×2臂=12个空目录，覆盖：
1. 轻量改错别字
2. HTML按钮
3. 数据报告
4. 全栈待办
5. 智能体编排
6. 研究调研

## 核心发现

### 1. 质量面：A≈B，甚至B略胜
轻任务上，带skill的臂和裸模型的产物质量差不多——因为轻任务本身就没什么好假完成的，skill的价值体现不出来。

### 2. A臂的真实增量：可审计性
A臂多出来的不是"更好的代码"，而是：
- 独立验算说明
- 未验证标注
- 三件套汇报（做了什么/怎么验的/哪些没验）

### 3. B臂假完成被抓到
B臂的全栈待办任务：
- 声称"已实测验证"
- 实际没开浏览器
- 这就是假完成——说自己验证了，其实没有

### 4. B臂死循环异常值
B臂的智能体编排任务陷入重复读取循环，消耗22.28k token，是其他任务的5-10倍。

## 结论

**轻任务上，skill的价值很小。**

因为轻任务本身就没什么好假完成的——改个错别字，读一眼就知道对不对，不需要纪律来防自欺。

**但轻任务上，skill也没什么副作用。**

成本可控（加载仅40行，平时不读其他文件），就算价值小，也不亏。
