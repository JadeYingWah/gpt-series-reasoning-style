# 个人作品集网站

一个响应式的个人作品集网站，使用 HTML、CSS 和原生 JavaScript 构建。

## 功能特性

- 🏠 首页：个人介绍、技能展示、精选项目
- 💼 项目展示：项目列表、分类筛选
- 👤 关于页：个人经历、教育背景、兴趣爱好
- 📧 联系页：联系表单、联系方式
- 📱 响应式设计：支持移动端、平板、桌面
- 🎨 现代化视觉：深色主题、渐变、微动效
- ⚡ 交互功能：导航、表单验证、项目筛选、平滑滚动

## 技术栈

- HTML5
- CSS3（Flexbox、Grid、CSS 变量）
- 原生 JavaScript（无框架依赖）

## 项目结构

```
portfolio/
├── index.html      # 首页
├── projects.html   # 项目展示页
├── about.html      # 关于页
├── contact.html    # 联系页
├── css/
│   └── style.css   # 样式文件
├── js/
│   └── main.js     # JavaScript 文件
└── README.md       # 说明文档
```

## 使用方法

直接在浏览器中打开 `index.html` 即可查看网站。

## 浏览器兼容性

- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+
