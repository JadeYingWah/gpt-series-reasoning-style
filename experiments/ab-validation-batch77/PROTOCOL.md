# A/B 验证实验协议 - Batch 77

## 实验目标
验证 gpt-series-reasoning-style skill (v1.2.0 + batch 75-77 改进) 是否能提高 AI 产出的产物质量。

## 实验设计
- **A 臂**：使用 gpt-series-reasoning-style skill 完整流程
- **B 臂**：不使用 skill，直接执行（基线）
- **任务**：创建一个个人作品集网站，包含首页、项目展示页、关于页和联系页，使用 HTML/CSS/JavaScript，要求响应式设计、现代化视觉风格、完整的交互功能

## 评估维度（每项0-10分）
1. **产物质量**（40%）：功能完整性、代码质量、视觉效果、响应式
2. **流程合规性**（20%）：验证、证据报告、文件整理
3. **用户思维**（15%）：从用户视角考虑、交互设计
4. **边界覆盖**（15%）：异常情况、错误处理、边缘案例
5. **诚实标记**（10%）：UNVERIFIED 标记、已知问题声明

## 执行规则
- 两个臂使用相同的任务描述
- 两个臂使用独立的工作目录，避免污染
- 先执行 B 臂（基线），再执行 A 臂（使用 skill）
- 每个臂完成后，立即记录产物和过程
- 评估由第三方视角进行，避免偏见

## 任务描述
"创建一个个人作品集网站，包含以下页面：
1. 首页：个人介绍、技能展示、精选项目
2. 项目展示页：项目列表、项目详情、筛选功能
3. 关于页：个人经历、教育背景、兴趣爱好
4. 联系页：联系表单、社交媒体链接、联系方式

技术要求：
- 使用 HTML5、CSS3、原生 JavaScript
- 响应式设计（移动端、平板、桌面）
- 现代化视觉风格（深色主题、渐变、微动效）
- 完整的交互功能（导航、表单验证、项目筛选、平滑滚动）
- 代码结构清晰，有注释

交付物：
- 完整的网站文件（HTML/CSS/JS）
- 一个 README.md 说明文件
- 所有文件放在一个目录下"
