# 命令行笔记工具（M1-notes）

零依赖的 Python 命令行笔记工具：新增、列表/过滤、搜索、统计，四个命令共享同一份 JSON 存储（notes.json）。

## 环境要求

- Python 3.7+（仅用标准库，无需安装任何第三方包）
- Windows / macOS / Linux 均可

## 安装

无需安装。将本目录所有 `.py` 文件放在同一目录下，直接用 `python` 运行即可：

```bash
python add.py --help
```

## 数据存储

- 数据文件为脚本同目录下的 `notes.json`（UTF-8 编码），首次运行任一命令时自动创建。
- 写入采用"临时文件 + 原子替换"（`os.replace`），避免写入中断导致数据损坏；文件损坏（非法 JSON）时命令报错退出且**不覆盖旧数据**。
- 四个命令共享同一存储：任一命令写入后，其余命令立即可见。

## 四个命令

### 1. add.py —— 新增笔记

```bash
python add.py "标题" "内容"                                     # 基本用法
python add.py "会议纪要" "讨论 Q3 计划" --tag 工作 --tag 计划    # 打标签（--tag 可重复）
```

- 自动记录创建时间戳（本地时间）、自动分配自增 id（现有最大 id + 1，不会重复）。
- 标题为空或全空白：报错退出（exit 1），不写入。
- 内容允许为空字符串。
- 标签写入端为 `--tag` 参数（任务定义中 list.py 的 `--tag` 过滤需要数据来源）。

### 2. list.py —— 列出笔记

```bash
python list.py                # 列出全部
python list.py --tag 工作     # 只列出包含标签「工作」的笔记（精确匹配）
```

- 表格对齐输出（中文全角字符按 2 列宽计算）。
- 无笔记 / 无匹配标签时输出提示并正常退出（exit 0）。

### 3. search.py —— 搜索

```bash
python search.py 计划
python search.py todo         # 大小写不敏感，可匹配 TODO、Todo
```

- 在**标题和内容**中做子串模糊匹配，大小写不敏感。
- 结果含内容预览（超长截断为 ...）；关键词为空/全空白时报错退出（exit 1）。

### 4. stats.py —— 统计

```bash
python stats.py
```

输出三部分：笔记总数、最新 3 条（按 id 从新到旧）、最长笔记（按内容字符数计，附预览）。

## 退出码

| 退出码 | 含义 |
|---|---|
| 0 | 成功（含"无结果"的正常情况） |
| 1 | 运行时错误（如标题/关键词为空、notes.json 损坏） |
| 2 | 参数错误（argparse 默认，如缺少必填参数、未知选项） |

## 已知边界与限制

- 特殊字符（引号、`&`、`<>`、emoji、换行、制表符等）均可写入并以 JSON 安全存储；表格内换行/制表符会被压平为单行显示。
- East Asian Ambiguous 字符（如 `·`、`±`）按 1 列宽计算，个别终端下可能有 1 列对齐误差。
- 终端编码不支持某字符时输出替代符而非崩溃；若显示乱码，可设置 `PYTHONIOENCODING=utf-8` 或使用 Windows Terminal。
- 未做多进程写锁，请避免多个命令同时写入。

## 文件结构

```
add.py        新增笔记
list.py       列出 / 按标签过滤
search.py     关键词搜索（大小写不敏感）
stats.py      统计（总数 / 最新 3 条 / 最长笔记）
storage.py    共享读写与表格渲染逻辑
notes.json    数据文件（脚本自动创建，可随时删除重建）
evidence/     验证证据（测试命令与输出记录）
```
