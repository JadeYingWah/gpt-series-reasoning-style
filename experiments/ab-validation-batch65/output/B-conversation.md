## 二、设计思路

### 2.1 整体架构：多层 Canvas 叠加

采用 **9 层 Canvas 绝对定位叠加** 的渲染架构，每层负责一个视觉维度，互不干扰、独立重绘：

```
z-index 层级（从底到顶）：
1. skyCanvas       — 天空渐变（时间+天气驱动）
2. starCanvas      — 星空（夜间闪烁）
3. celestialCanvas — 太阳/月亮（弧线轨迹运动）
4. cloudCanvas     — 云朵（蓬松粒子组合，随风漂移）
5. fogCanvas       — 雾层（多层正弦波叠加）
6. particleCanvas  — 雨滴/雪花粒子系统
7. cityCanvas      — 城市剪影（远近两层建筑+窗户灯光）
8. groundCanvas    — 地面（雨天湿地反射/雪天积雪）
9. glowCanvas      — 氛围光（日出日落霞光+夜间光污染+暗角）
```

### 2.2 颜色系统：多色标时间插值

每种天气预设一套天空色标（顶部色 + 底部色），按 24 小时定义关键帧颜色。运行时通过 `gradientColor()` 函数在相邻色标间做线性插值，实现天空颜色的**逐帧平滑过渡**。

以晴天为例，关键时间节点：
- **00:00 深夜**：深蓝黑 `#050816`
- **06:30 日出**：紫蓝过渡 `#3d4a7a`
- **07:30 清晨**：暖橙地平线 `#e8b080`
- **12:00 正午**：明亮天蓝 `#2e7fd4`
- **18:00 日落**：橙红 `#c47a5a`
- **19:00 黄昏**：紫红 `#8a4a6a`
- **21:00 入夜**：深蓝 `#151a3a`

### 2.3 五种天气状态

| 天气 | 视觉特征 | 粒子 | 天空基调 |
|------|----------|------|----------|
| ☀️ 晴朗 | 明亮天空、强烈太阳光晕、稀疏白云 | 无 | 蓝色渐变 |
| ⛅ 多云 | 厚云覆盖、漫射光、太阳若隐若现 | 无 | 灰蓝 |
| 🌧️ 降雨 | 暗灰天空、密集雨线、湿地反光 | 300 雨滴 | 深灰 |
| 🌨️ 降雪 | 灰白天空、飘落雪花、地面积雪 | 200 雪花 | 浅灰 |
| 🌫️ 雾天 | 多层雾霭、低能见度、 muted 色调 | 无 | 灰蒙 |

### 2.4 昼夜光影循环

- **太阳轨迹**：6:00 从地平线升起，沿正弦弧线运动，18:00 落下
- **月亮轨迹**：18:00 升起，次日 6:00 落下，带环形山细节
- **星星**：夜间可见，带闪烁动画，雾天/雨天自动隐藏
- **建筑窗户**：夜间自动亮灯（暖黄色），带随机闪烁
- **天线红灯**：高层建筑天线夜间闪烁航空警示灯
- **日出/日落霞光**：地平线径向光晕，仅在晴/多云天气显现
- **夜间光污染**：城市上空暖色辉光

### 2.5 气象数据模型

温度采用正弦日变化曲线（最低 ~5:00，最高 ~15:00），叠加天气基准温度偏移；湿度、风速、体感温度、能见度、气压均基于天气类型 + 时间变化 + 微小随机扰动计算，数据每 10 帧刷新一次避免抖动。

## 三、实现要点

### 3.1 粒子系统

- 预分配 400 个粒子对象池，避免运行时 GC
- 雨滴：斜线下落，速度 12-18 px/帧，带风向偏移
- 雪花：正弦摆动飘落，速度 1.5-3.5 px/帧，大小 1.5-4px
- 非雨雪天气粒子透明度渐隐至 0，而非瞬间消失

### 3.2 城市剪影生成

- 程序化生成两层建筑（远景 + 近景），宽度/高度随机
- 每栋建筑自动生成窗户网格，随机点亮状态
- 三种屋顶类型：平顶、设备顶、阶梯顶
- 部分建筑带天线，夜间闪烁红灯

### 3.3 交互系统

| 交互方式 | 功能 |
|----------|------|
| 拖动时间滑块 | 即时改变时间 |
| 播放/暂停按钮 | 自动推进时间 |
| 速度选择 (1x/5x/20x) | 控制时间流逝速度 |
| 天气按钮 | 切换 5 种天气 |
| 空格键 | 播放/暂停 |
| ←/→ 方向键 | 时间 ±10 分钟 |
| 数字键 1-5 | 快速切换天气 |
| 点击场景 | 播放/暂停 |

### 3.4 UI 设计

- **毛玻璃面板**：`backdrop-filter: blur(20px)` + 半透明背景
- **左侧气象面板**：大字号温度 + 6 项气象指标
- **右侧天气选择器**：圆形图标按钮 + hover tooltip
- **底部控制栏**：时间刻度 + 自定义滑块 + 播放控制 + 速度
- **顶部时钟**：等宽数字字体，实时显示 HH:MM:SS
- **昼夜徽章**：动态显示当前时段（黎明/日出/正午/黄昏/深夜等）
