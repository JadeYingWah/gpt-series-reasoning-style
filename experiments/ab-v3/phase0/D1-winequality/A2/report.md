## 二、方法

- 加载：Python 标准库 `csv.DictReader`（`delimiter=";"`），全部列转 float，不依赖 pandas。
- 相关系数：Pearson 定义式 r = Σ(x−x̄)(y−ȳ) / √(Σ(x−x̄)²·Σ(y−ȳ)²)，对 11 个特征逐一计算。
- 计数与分组均值：列表条件筛选 + 算术平均，另用 numpy 独立复算均值。
- 脚本：`analysis.py`（本目录），一次运行输出全部三项答案并内置断言电池。

环境说明：本机默认 python 3.13 及 py -3.13/-3.12 缺 numpy；py -3.14 含 numpy 但 pandas/scipy 损坏不可用。故采用 stdlib csv + numpy 双实现方案（见 `analysis.py` 头注释），已验证不影响结果正确性。

## 三、如何验证自己的数字

1. **数据完整性断言**：行数=1599、列数=12、无 NaN/Inf、quality∈[3,8] 且为整数 —— 全部通过。
2. **双实现交叉验证**：手工 Pearson 公式 vs `numpy.corrcoef`，11 项系数最大偏差 2.78e-16（远小于 1e-9 阈值）；分组均值 numpy 复算偏差 <1e-12。两种实现独立编写，同错概率可忽略。
3. **守恒断言**：quality 六档计数总和 = 1599（守恒）；高/低质组 n=217/63，两组不重叠且均非空。
4. **外部一致性抽查**：计数分布（10/53/681/638/199/18）与 alcohol 相关性约 +0.476 同 UCI 该公开数据集的已知公开数值一致（凭记忆比对，标注 UNVERIFIED 佐证级，不作为主要证据）。
5. **反例检验（通过率≠鉴别力）**：断言中若人为改动任一相关系数小数或计数（如把 53 改 54），形状/守恒/交叉偏差断言会立即失败——断言电池对目标错误有杀伤力，非恒真。
