# D2 · 咖啡馆销售数据清洗报告

- 数据文件：`<实验根目录>\ab-v3\datasets\cafe_sales_dirty.csv`（10 000 行交易，8 列）
- 缺失标记（R1）：strip 后为 `ERROR` / `UNKNOWN` / 空字符串（大小写不敏感处理）
- 分析脚本：`clean_and_analyze.py`（本目录），复现命令：`python clean_and_analyze.py`

## 方法

1. 主实现：纯 Python（csv 模块）逐行清洗聚合。
2. 独立交叉验证：sqlite3（内存库 + SQL 聚合）完全独立重算全部指标。
3. 两套实现所有指标**完全一致**（脚本退出码 0，差异列表为空）。
4. 变异验证：向数据副本注入一条 TS=999 的不一致行，Q5 检测逻辑正确报出 1 条（会红）；原始数据中 TS/Quantity/Price 均有效的 8 544 行最大 |TS−Q×P| = 0.0，证明 Q5=0 是真实结果而非检测逻辑空转。临时变异文件已删除。
