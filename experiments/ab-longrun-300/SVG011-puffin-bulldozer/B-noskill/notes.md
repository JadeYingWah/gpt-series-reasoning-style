# SVG011-puffin-bulldozer · 几何与运动自洽说明

## 场景设定

- 视角：正侧视（观众在车辆左侧，看向右方）
- 行进方向：**画面右侧**（blade / 推土铲在车体右前方）
- 风格：北极海岸暮色 · 工程插画，非白底扁平占位图标

## 运动自洽规则

### 1. 前进方向一致性（全部向右）

所有循环动画的相位方向必须表现为「车向右开」：

1. **履带花纹**  
   - 实现：`stroke-dasharray: 8 12` + `stroke-dashoffset` 从 0 → −40  
   - 视觉：花纹沿履带路径向 **左** 移动  
   - 物理：车向右时，履带相对车体向左卷 → 一致 ✓

2. **负重轮 / 主动轮**  
   - 实现：`rotate(0 → 360deg)`，`transform-origin: center`，顺时针  
   - 物理：侧视、车向右 → 车轮顺时针 → 一致 ✓

3. **背景视差层**（`translateX` 负方向滚动）
   - 远云 48s / 近云 28s
   - 远冰山 60s / 中景浮冰 36s
   - 近景砾石与道路标线 8s（最快，景深最近）
   - 全部向左滚 = 车相对地向右 → 一致 ✓

4. **排气烟圈**  
   - 向左上飘散 → 车向右运动的相对气流 → 一致 ✓

5. **履带扬尘**  
   - 在车体左后方（画面左）出现，向左扩散 → 一致 ✓

### 2. Puffin 附肢相对运动（≥2 处，非全身锁死）

puffin **不是**随车体整体平移；以下肢体有独立动画轨道：

| 附肢 | 独立动画 | 周期 | 相位特征 |
|------|----------|------|----------|
| **头部** `#puffin-head` | 点头 + 小幅偏转 (rotate ±4°) | 2.1s | 与车体 0.28s 弹跳不同相 |
| **左翼** `#wing-left` | 推蓝色操纵杆 (rotate −18°…+8°) | 1.1s | 独立周期 |
| **右翼** `#wing-right` | 扳红色手柄 (rotate +14°…−10°) | 1.35s | 与左翼异相 |
| **左脚** `#foot-left` | 踏板踩踏 | 0.7s | |
| **右脚** `#foot-right` | 踏板踩踏 | 0.7s + 0.35s delay | 与左脚交替 |
| **尾羽** `#puffin-tail` | 摆动 ±7° | 1.6s | 独立 |

车体自身另有 `engine-bounce`（0.28s）与 JS 注入的 ~3.2s 侧倾 idle sway。  
→ 头 / 双翼 / 双脚 / 尾 相对车体均有可见相对运动，**不满足「全身锁死平移」**。

### 3. 背景景深（≥2 层视差）

由远及近：

1. 天空渐变 + 星点（静止）
2. 太阳光晕脉冲
3. **远云层**（48s 漂移，半透明）
4. **远冰山/山脉**（60s 滚动）
5. 海面 + 波峰（微闪烁）
6. **中景浮冰**（36s 滚动）
7. **近景砾石地面**（8s 滚动）
8. 道路标线（8s）
9. 前景草丛/冰屑 + 扬尘（8s）

至少 5 层速度不同的横向滚动，构成完整视差栈。
