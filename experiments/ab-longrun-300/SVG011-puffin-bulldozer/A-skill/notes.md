# SVG011 · Puffin Bulldozer — 实现说明（自洽 / 几何 / 运动）

## 主题

一只 **Atlantic Puffin**（大西洋海鹦）坐在黄色 **bulldozer** 驾驶位上，向画面 **右侧** 沿沙丘海岸前进。风格：扁平 + 渐变的儿童绘本插画感，暖沙色海岸 + 午后阳光，非白底占位图标。

## 几何与运动自洽

### 1. 履带 / 车轮循环与前进方向一致

| 元素 | 方向 | 物理含义 |
|------|------|----------|
| `.tread-belt`（履带板 pattern） | 向左 translate（`0 → -28px`） | 车辆向右前进时，接地面相对车身向后（左）滑动，符合无滑滚动 |
| `.road-wheel`（三个负重轮） | **顺时针** `rotate(0→360deg)` | 屏幕坐标系下，向右前进的轮子应顺时针转 |
| 推土铲朝向 | 画面右侧（+X） | 与前进方向一致：铲刀在前 |

CSS 中 `@keyframes beltScroll { to { transform: translateX(-28px) } }` 与 pattern tile 宽度 28px 对齐，保证无缝循环。

### 2. Puffin 附肢相对载具的运动（≥2 处，非全身锁死平移）

整机 `#dozer-rig` 有颠簸 bob（0.55s），puffin 在此基础上 **叠加** 以下独立相位/频率的附肢动画：

1. **双翼** `.wing-left` / `.wing-right` — 绕肩关节摆动，抓握操纵杆；左右翼延迟/幅度不同（右翼更大，近侧）
2. **头部** `#puffin-head` — 1.1s 周期俯仰/侧倾，频率约为车身的一半，形成相对相位
3. **尾羽** `#puffin-tail` — 0.35s 快速扇动（频率高于车身 bob）
4. **整体 rider bounce** `#puffin-root` — 与 `#dozer-rig` 同周期但幅度/原点不同（不是简单锁死）

因此 puffin 不是「全身锁死随车平移」：翼、头、尾相对驾驶室有清晰相对运动。

### 3. 背景 ≥2 层视差

从远到近三层，全部向左平移、周期不同（越近越快）：

| 层 | class | 周期 | 内容 |
|----|-------|------|------|
| 远 | `.parallax-far` | 48s | 远山轮廓（半透明） |
| 中 | `.parallax-mid` | 28s | 海岸灌木丘、小屋、树丛 |
| 近 | `.parallax-near` | 12s | 沙丘地面、沙纹、近灌木、碎石 |

每层将同一几何 **画了两份**（`translate(0)` 与 `translate(1400)`），配合 `translateX(-1400px)` 循环，形成无缝视差。天空 + 太阳为静态基底（不参与视差，作为无限远）。

### 4. 其它运动细节

- **排气烟** `.smoke`：从排气管向上飘散，3 粒交错延迟
- **履带扬尘** `.dust`：从履带后方（左侧）向左后方抛散
- **铲刀刃口高光** `#blade-edge`：呼吸式闪烁
- **整车 bob** `#dozer-rig`：微小位移 + 旋转，模拟发动机振动

## 可辨认性设计

### Puffin
- 黑背 + 白脸/白胸
- 大型三角彩喙（橙红渐变 + 喙板分节线）
- 眼周小白区 + 三角眼纹
- 橙色脚蹼

### Bulldozer
- 履带 + 三个负重轮 + 前后诱导轮
- 黄色机身 + 发动机舱格栅 + 排气管
- 驾驶室 ROPS 框 + 座椅 + 双操纵杆
- 前置大型铲刀 + 被推起的土堆

## 交互（JS，可选增强）

点击/键盘触发 2.2s **turbo**：所有循环动画 duration 减半。无 JS 时页面完全静态可看（纯 CSS 动画已足够）。
