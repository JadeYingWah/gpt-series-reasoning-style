# SVG001-octopus-excavator · 几何/运动自洽说明

## 前进方向

- 画面约定：**+X = 右侧**。章鱼挖掘机整体朝右前进。
- 履带胎面 `stroke-dasharray` + `stroke-dashoffset` 动画向负方向滚动，相对底盘表面向右移动，与前进方向一致。
- 负重轮 / 驱动轮 / 诱导轮使用 CSS `rotate` **顺时针**（`wheel-cw`），与右前进一致。
- 地面刻痕 `.ground-marks` 向左滚动，反向衬托载具向右。

## 章鱼相对载具的肢体运动（≥2 处，非全身锁死）

| 附肢 | class | 周期 | 说明 |
|------|-------|------|------|
| 左操作臂 | `.arm-ctrl-L` | 1.3s | 抓左操纵杆，绕根部旋转 + 轻微 Y 位移 |
| 右操作臂 | `.arm-ctrl-R` | 1.55s | 抓右操纵杆，相位/幅度与左臂不同 |
| 悬垂臂 | `.arm-hang` | 2.1s | 伸向驾驶室外左侧，大幅度摆动 |
| 挥舞臂 | `.arm-wave` | 1.7s | 伸向右侧窗外，含 scaleY 形变 |
| 内收臂 | `.arm-tuck` | 2.8s | 短促内收，周期最长 |
| 头部 | `.octo-head` | 1.8s | 上下点头 3px |
| 眨眼 | `.eye-lid` | 4.2s | 眼睑 scaleY 闪动 |

以上均相对底盘独立动画，**不**与 `.vehicle-bob`（2.4s）锁相。

## 载具自身循环

- 履带胎面：`tread-scroll` 0.55s
- 车轮：`wheel-cw` 1.1s（= 胎面一周节奏的约 2 倍）
- 车体俯仰：`bob` 2.4s
- 动臂 / 斗杆 / 铲斗挖掘循环：`boom-dig` / `stick-curl` / `bucket-curl` 均为 3.6s，相位错开

## 视差 / 景深（≥2 层）

| 层 | class | CSS 漂移周期 | JS 指针视差系数 | 内容 |
|----|-------|--------------|-----------------|------|
| L0 天空 | — | 静止 | — | 渐变 + 月晕 |
| L1 远景 | `.layer-far` | 80s | ×6 | 星点、远山剪影 |
| L2 中景 | `.layer-mid` | 40s | ×14 | 工业天际线 / 塔吊剪影 |
| L3 近景 | `.layer-near` | 18s | ×28 | 前景杂草 |
| 地面 | `.ground-marks` | 1.1s | — | 滚动刻痕 |

CSS 层自动水平漂移；JS 在 `mousemove` 时按深度系数叠加视差偏移（纯增强，无指针时场景仍完整动画）。

## 外部资源

- **无** CDN、框架、网络请求、`<img>`、`<image href>`、`<script src>`、`<link href>`。
- 全部 CSS / JS / SVG 内联于 `art.html`。

## 主体可辨认性

- **Octopus**：品红头部外套膜、双眼（含高光/眼睑）、漏斗、至少 6 条带吸盘的触腕。
- **Excavator**：履带底盘、回转平台、橙色机身、驾驶舱玻璃、动臂+斗杆+铲斗、排气筒、警示灯、前灯。
