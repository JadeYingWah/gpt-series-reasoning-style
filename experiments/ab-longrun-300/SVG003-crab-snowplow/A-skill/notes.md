## 构图

- 画布 `viewBox="0 0 1280 720"`，主体扫雪车居中偏右，车头朝 **+X（画面右侧）**。
- 风格：极夜 / 北境蓝调（深靛夜空、青绿极光、冷雪）+ 珊瑚红赤甲蟹作视觉焦点；工业钢灰车身、危险条纹铲刀、琥珀色警灯。
- 非「白底 + 扁平占位图标」：完整分层插画 + 径向/线性渐变 + 纹理与光晕。

## 前进方向与循环动画的一致性

约定：**车朝画面右（+X）前进**。相对运动 = 背景向左（-X）平移。

| 循环元素 | 实现 | 与前进方向的关系 |
|----------|------|------------------|
| 车轮 `.wheel-spin` | `rotate(360deg)`，`0.9s linear infinite` | **顺时针** = 向右滚动 |
| 轮胎花纹 `.belt-marks` | `stroke-dashoffset` 从 `0` → `-28` | 花纹向左后掠，与向右滚动一致 |
| 地面胎痕虚线 | 同上 `belt-marks` | 痕迹相对车向左流，暗示车右行 |
| 山地/丘陵/地面视差 | `translateX(0 → -640px)` | 背景左移 = 相对车右移 |
| 排气烟 `.puff` | 向左上漂移 `(-40, -55)` | 废气向后（左）排出 |
| 铲雪喷射 `.spray-*` | 向右上抛出 `(+48, -28)` | 雪被前进的铲刀向右前方抛洒 |

周期对照：车轮与胎痕同为 `0.9s`，保证「转一圈 ≈ 花纹步进一致」的视觉同步。

## 视差 / 景深（≥2 层）

由远及近，滚动周期递减（越近越快）：

1. **星空** `plx-stars` — 120s，几乎静止的极远层  
2. **极光带** `plx-aurora` — 90s，大气光幕  
3. **远山** `plx-mtn-far` — 70s，冷色剪影 + 雪冠  
4. **中山** `plx-mtn-mid` — 42s，更近的山脊  
5. **丘陵 + 松树** `plx-hills` — 22s，中景植被  
6. **雪地地面** `plx-ground` — 10s，最近可滚动地形（冰面高光、双轨胎痕）  
7. **前景降雪** `snow-far` / `snow-near` — 14s / 7s 垂直下落，近层更大更实  

各层循环位移均为 `640px`，形状在 tile 内重复绘制，保证无缝衔接。

## 附肢相对载具的独立运动（≥2 处，禁止全身锁死）

载具底盘 `.chassis`：整体 **上下弹跳 + 微滚转**（`bob`，0.55s），模拟不平雪面。

螃蟹肢体（各自独立 class / 周期，不与 chassis 绑死）：

| 附肢 | 动画 | 周期 | 相对关系 |
|------|------|------|----------|
| 左螯 `.claw-l` | 绕握持点旋转 ±7° | 1.7s | 握方向盘，独立夹持脉动 |
| 右螯 `.claw-r` | 绕握持点旋转 ±6° | 1.9s | **与左螯不同相/不同周期** |
| 左眼柄 `.eye-stalk-l` | ±4–5° 摆动 | 2.1s | 独立于底盘与螯 |
| 右眼柄 `.eye-stalk-r` | ±6–3° 反向摆 | 1.6s | 与左眼不同步 |
| 瞳孔 `.pupil` | 水平瞥视 +2.5px | 3.4s | 眼球相对眼柄再动一层 |
| 触角 A/B `.antenna` | ±8–10° 挥动 | 1.4s / 1.75s | alternate-reverse 错相 |
| 步足 `.leg-walk-a/b` | ±3–4° 撑地 | 0.55s | 与 bob 同频 **反相**，作避震支撑 |
| 方向盘 | 缓转 360° | 2.4s | 与车轮转速不同，避免「假锁死」 |

结论：至少螯×2、眼柄×2、触角、步足共 3 类以上附肢与载具相对运动；全身并非刚体平移。

## 其他自洽细节

- 车头朝右：前灯与光锥在 `x≈914`，铲刀在 `x≈920–1075`（前），排气在 `x≈540`（后）。
- 铲刀前缘有雪堆与抛雪粒子，说明正在推雪。
- 地面有向左延伸的双轨胎痕与 dashed marks，说明已行驶一段。
- 驾驶室内可见方向盘、座椅靠背、门把手；蟹在窗后，肢体透过玻璃可读。
- 警灯在车顶，旋转闪烁；前灯 beam 随车头朝右。
- `prefers-reduced-motion: reduce` 时关闭全部动画（可访问性）。
- 标签页隐藏时 JS 将 `animationPlayState` 置 `paused`（省电）。
