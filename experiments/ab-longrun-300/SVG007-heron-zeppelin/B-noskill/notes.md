# 几何/运动自洽说明 — SVG007-heron-zeppelin

工作目录：`<实验根目录>\ab-longrun-300\SVG007-heron-zeppelin\B-noskill`
交付文件：`art.html`（单文件，CSS/JS 内联，无 CDN/框架/网络请求）

## 场景概述

黄昏天际，一只苍鹭（heron）驾驶复古齐柏林飞艇（zeppelin）朝画面右侧前进。
气囊为奶金色，木质吊舱，右侧（前进方向）主螺旋桨 + 左侧副螺旋桨同相旋转。
背景由远及近分层：星空 → 远山剪影 → 远云 → 中云 → 近景雾丝 → 速度线/粒子。

## 1. 推进器循环与前进方向一致

| 元素 | 实现 | 与前进方向关系 |
|------|------|----------------|
| `#prop-r` | CSS `rotate(0→360deg)`，`0.28s` linear infinite | 右侧推进器顺时针（从画面右侧观察）→ 产生向右推力 |
| `#prop-l` | 同相位顺时针旋转 | 副推进器辅助，方向一致 |
| `.thrust-stream` | 从左向尾部流动的短线段 | 尾流朝后（左）喷出，符合向右前进 |
| `.speed-line` | 近景速度线 translateX 负向 | 线条向左掠过，相对运动表明载具向右 |

飞行器无车轮/履带；螺旋桨循环动画已覆盖「循环动画与前进方向一致」要求。

## 2. Heron 至少 2 处肢体/附肢相对载具独立运动

实现为 **5 处** 独立动画（均锚定关节 `transform-origin`，全身不锁死平移）：

| ID | 部位 | 动画 | 周期 | 相对关系 |
|----|------|------|------|----------|
| `#heron-neck` | S 形长颈 | rotate -5° ~ +6° | 1.8s | 独立于 gondola-swing / zeppelin-bob |
| `#heron-head` | 头（neck 子级） | rotate -4° ~ +3° | 2.9s | 再叠一层，双重非同步 |
| `#heron-wing-front` | 前翼（理羽/操纵） | rotate 0° ~ -18° | 1.1s | 大幅独立抬降 |
| `#heron-wing-back` | 后覆羽 | rotate 0° ~ +4° + translateY | 1.7s | 相位不同 |
| `#heron-leg-dangle` | 双腿吊挂 | rotate -3° ~ +5° | 2.4s | 相对吊舱独立摆动 |
| `#heron-crest` | 羽冠饰羽 | rotate -8° ~ +6° | 1.4s | 附加细节 |

所有周期均与 `zeppelin-bob`(3.6s)、`zeppelin-pitch`(5.2s)、`gondola-swing`(4.4s) 互不整除对齐，避免锁死同步。

## 3. 背景至少 2 层视差/景深

实现为 **5 层** 速度不同的水平漂移：

| 层 | ID | 动画时长 | 幅度 | 速度档 |
|----|-----|----------|------|--------|
| 极远 星空 | `#layer-stars` | 90s | 40px | 最慢 |
| 远 山剪影 | `#layer-mtn` | 120s | 60px | 极慢 |
| 中远 云 | `#layer-cloud-far` | 80s | -20% | 慢 |
| 中 云 | `#layer-cloud-mid` | 48s | -28% | 中 |
| 近 雾丝 | `#layer-wisp` | 28s | -36% | 快 |
| 近 粒子 | `#layer-particles` | 14s | -50% | 最快 |

云层图形做了无缝循环副本（重复一份偏移约 +1280~+1480px），避免漂移时露空。

主体 `#zeppelin-rig` 做 bob（3.6s / ±10px）+ pitch（5.2s / ±1.2°），与背景相对运动形成「世界系前进」的景深感。

## 4. 几何自洽要点

- 苍鹭 S 颈、长喙朝右（与飞行方向一致），羽冠后飘。
- 尾鳍在气囊**左**端（后方），三片各自有相位差的 flick。
- 吊缆从气囊底部连接吊舱；吊舱内有操纵杆、罗盘、舷窗灯。
- 罗盘指针 `#compass-needle` 有独立 wobble，暗示真实仪表。
- 气囊筋线、金色包边、徽章增强体积感；无默认扁平图标、无纯白底。

## 5. 技术约束

- 纯 HTML + SVG + CSS keyframes，无 JS 依赖亦可播放（JS 非必需）。
- 无外部字体、无 CDN、无网络请求、无框架。
- `viewBox="0 0 1280 720"`，自适应容器。
