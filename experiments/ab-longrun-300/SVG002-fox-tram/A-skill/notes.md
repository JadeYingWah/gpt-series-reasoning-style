# notes.md — SVG002-fox-tram 几何与运动自洽说明

作品：`art.html` · 方向自选：**夜班电车 · Night Tram**（电影感夜景 / 吉卜力式黄昏列车）

> 本次方向为冒险直选（创意任务方向豁免）。范围与落盘路径由 `task.md` 锁定。

---

## 1. 场景坐标系

- SVG `viewBox="0 0 1200 700"`，`preserveAspectRatio="xMidYMid slice"`
- 前进方向：**+x（画面右侧）**
- 轨面约 y=545–572，车轮心 cy≈530
- 电车主体包络：x≈345–910（含排障器），y≈168–512（含受电弓与烟囱）

---

## 2. 车轮 / 轨道循环与前进方向一致

| 元素 | 参数 | 与前进关系 |
|---|---|---|
| 前轮 | cx=780, r=30，`spin-cw` 0.9s | 顺时针 = 车向右滚 |
| 中轮（转向架） | cx=580, r=18，0.75s | 同向，略快（半径小、角速度略高，符合滚动接触近似） |
| 后轮 | cx=420, r=30，0.9s，delay −0.22s | 顺时针；相位偏移制造轮对不同步的机械感 |
| 枕木层 `#layer-track` | `translateX(0 → −200px)` / 9s | 背景向左滚 = 相对车体向右前进 |
| 近景电杆 `#layer-poles` | `translateX(0 → −400px)` / 7s | 比轨道更快，符合「越近越快」 |

`transform-origin` 对轮组使用 `fill-box` + `center`，保证绕自身几何中心旋转。

---

## 3. Fox 附肢相对载具的运动（≥2 处，非全身锁死平移）

Fox 固定在驾驶室局部坐标（`translate(800,300)`），以下节点各自有独立动画：

1. **头组 `#fox-head-group`** — `head-bob` 2.4s：轻微平移 + 摆头（±1.5°），模拟颠簸中的驾驶姿态。
2. **左耳 `#fox-ear-l` / 右耳 `#fox-ear-r`** — 不同时相的 `ear-twitch`（3.1s / 2.7s），单耳偶发抽动。
3. **尾 `#fox-tail`** — `tail-sway` 1.8s，绕尾根 −6°↔+10°，惯性甩尾。
4. **围巾 `#fox-scarf`** — `scarf-flutter` 1.4s，平移 + skew，模拟相对气流向后飘。
5. **右臂 `#fox-arm`** — `arm-pull` 2.1s，绕肩点旋转拉控制器。
6. **躯干 `#fox-body`** — `body-breathe` 2.0s，微幅上下呼吸。

以上任一单独动画都相对电车局部坐标变化，**不是**整体 `#tram` 的平移拷贝，满足「附肢与载具非完全同步锁死」。

---

## 4. 背景视差层（≥2，实际 4 层滚动 + 1 层静态）

由远及近，速度递增（相对轨道 1.0×）：

| 层 id | 内容 | 动画周期 / 位移 | 等效倍率 |
|---|---|---|---|
| `#layer-stars` | 星空 + 月 | 48s / −100px | ≈0.10× |
| `#layer-city-far` | 远城剪影 + 微窗 | 36s / −100px | ≈0.13× |
| `#layer-city-mid` | 中景楼群 + 暖窗 + 雾 | 18s / −200px | ≈0.50× |
| `#layer-poles` | 近景电杆 / 树剪影 | 7s / −400px | ≈2.5× |
| `#layer-track` | 道砟 / 枕木 / 钢轨 | 9s / −200px | 1.0×（基准） |
| 静态 | 连续接触网线、轨下地面、车底阴影、vignette | 无 | 视觉锚定 |

层间速度差构成明确景深；接触网导线单独静态绘制，避免随电杆「跳动」。

## 5. 其他运动一致性

- **受电弓火花 `#panto-spark`**：3.7s 不规则闪烁，位置在接触鞋与导线接触点 (560,168)。
- **车头灯束 `#headlight-beam`**：沿 +x 从车头射出，亮度脉动 2.8s。
- **烟囱青烟**：三枚 puff 以 1.1s 错相向 **上后方（−x, −y）** 飘散——车向右前进，烟相对落后，合理。
- **车窗灯 `window-lamp`**：暖光脉动，与「夜班」叙事一致。
- **`prefers-reduced-motion: reduce`**：关闭全部动画，保留静帧构图。

## 7. 可辨认性设计要点

**Tram**：红色车体 + 奶油腰线、侧窗阵列、目的地牌「東環線 EAST LOOP」、线路牌「07」、受电弓、排障器、三轮转向架、前灯。

**Fox**：橙褐渐变毛色、尖耳（内耳浅色）、白吻、黑鼻尖、围巾、列车长帽（金徽）、蓬尾（白梢）、驾驶舱内面向右坐姿。
