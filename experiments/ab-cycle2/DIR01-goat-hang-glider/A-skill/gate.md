### 最高影响问题（供你判断，不是提问）
1. **可辨识性 vs 重叠糊团**：山羊与滑翔机同处一个紧凑画面，剪影极易互相吃掉（山羊被看成狗/鹿、载具被看成风筝）。需靠描边分离 + 明度对比 + 载具硬几何（三角翼、吊带、横杆、操纵杆）区分。
2. **"周期多"容易变成"各动各的"**：清单只要求 ≥2 个独立周期，但周期一多且无耦合，画面会显得随机漂浮、不成立。反之若强行同频，又违反映收项 4。→ 需**部分耦合**（如摆腿与俯仰设固定相位比），并把它写进 `notes.md`。
3. **朝向一致性是隐性失分点**：滑翔机朝右飞，则**所有视差层必须向左移动**（相机相对运动），山羊也必须面朝右。任一环节反向，验收项 2 直接失分，且肉眼别扭。
4. **离线是硬约束**：字体只能用系统字体栈（`system-ui` 等），不得引 webfont；不得引任何 `<script src>`/`<link href>` 外部资源。
5. **验收清单的鉴别力**：6 项都是"有没有"，全绿≠成品好。→ 收尾必须叠加**人眼审美复看**与上述杀伤率自检，否则"通过"不构成证据。
6. **体积/性能**：≥8KB 是下限，但视差层 + 渐变若堆砌过度会显著超出；计划控制在 **14–20KB** 区间，兼顾观感与体积。

### 推荐方案

**推荐方向：C-大胆（物理自洽的滑翔动力学 + 逐帧可验算），并吸收 B 的分层美术作为画面骨架。**

先给三个**真实不同**的方向（保守/均衡/大胆各一）：

#### 方向 A · 保守 —— 「极简几何扁平 · 黄昏巡航」
- **做什么**：纯几何构成（三角耳 + 梯形身体 + 细杆四肢＝山羊；等腰三角翼 + 吊带＝滑翔机），2 层视差（远山 / 中云），全部动画为固定周期的 CSS `@keyframes`，共约 7 组。
- **关键取舍**：把"稳"放在第一位——每一项验收都是**机械命中**，几乎不可能失分。代价是**辨识度风险转嫁到几何精度上**（山羊最容易画成狗或鹿），且画面偏平、缺乏纵深与光泽，属于"合格但不出彩"。工作量最小、返工概率最低。

#### 方向 B · 均衡 —— 「剪纸分层浮雕 · 高山气流」
- **做什么**：4 层视差（远雪山 / 中云带 / 近山脊 / 前景草坡），层速 1 : 2.5 : 5 : 10；山羊用**剪影 + 局部细节**（弯角、胡须、蹄、眼白）保证物种可辨；滑翔机带帆布质感（线性渐变 + 高光 + 缝线）。动画拆分为 6+ 独立周期（浮沉 6.0s / 摆腿 1.2s / 尾巴 1.6s / 胡须 0.8s / 涡流飘带 2.5s / 层移 30s·12s·5s·3s / 星点闪烁 2.0s）。
- **关键取舍**：观感与可辨性显著优于 A，成本主要是**视差层的几何绘制**；风险是"层级多 + 周期多"若不设约束会显得散，需要为耦合补一条相位规则。属于**性价比最优的安全强解**。

#### 方向 C · 大胆 —— 「可验算的滑翔动力学」
- **做什么**：在 B 的分层美术基础上，引入一条**闭合的因果链**替代"各转各的"：山羊摆腿（重心位移）→ 翼面俯仰角变化 → 伪"升力"函数 → 滑翔机高度（下沉/爬升）；同时**相机高度反向绑定视差层速度**（飞得越高，地景掠过越慢）。用固定步长确定性驱动，暴露 `stateAt(n)` 供任意帧重放，使得**任意时刻的高度、俯仰角、摆腿相位三者可解释、可反算**。
- **多做什么**：把"动画"升级为"可验算的运动学"——产出可被判分方**逐帧核对的不变量**（高度＝升力积分、相位比恒定、层速＝高度函数），而不是只能"看起来还行"。
- **冒什么险**：复杂度最高；耦合若做不真，**比不做更假**（假物理比装饰性漂浮更刺眼）；且引入驱动逻辑后**验收不能再只看源码**，必须真开浏览器取帧。另外"引入 JS 驱动"本身是一个需要你拍板的口径问题（见下）。
- **为什么值**：本任务的主质量维度是"矢量机械动画自洽性"，而本机已装 `svg-mechanism-animation-audit` 正是为这类"耦合关系可逐帧验算"的场景准备的——**用已装专家的能力去做它最擅长的事**，比交一份所有人都会交的安全解更接近上限；且它产出的证据是**可被证伪的**（杀伤率自检有靶子），鉴别力远高于存在性清单。

**为什么推荐它**：① 本 skill 明确"创意任务防的不是返工，是平庸；大胆是默认，保守才需要理由"；② 产物本地、完全可逆、无副作用，**审美方向的大胆不构成风险**；③ 已装 skill 恰好覆盖该维度，按门禁规则默认由它主导；④ C ⊇ B 的分层美术（视差层是验收项 3 的硬需求），故 C 并不牺牲 A/B 的合规底盘，只是在其上加了耦合内核。

**推荐方向的分镜与周期表（供成交后直接实现，节选）**

| 部件 | 周期 | 驱动方式 | 耦合关系 |
| --- | --- | --- | --- |

### 其他选项（我已评估并否掉，信息性、**不需要你选**）
- **Canvas 全量绘制**：像素级证据强，但违背"内联 SVG"的矢量意图，静态可读性与体积可控性都更差 —— 否。
- **外部素材（AI 生图 / 3D 模型 / 开源 SVG clipart）**：违反"单文件、无外部依赖、离线可渲染" —— 否。
- **纯 SMIL 承载全部动画**：keyframes 计数不直观、逐帧调试困难，且部分引用场景（作为 `<img>`）SMIL 不播 —— 否，改为 CSS 为主（若你要求零 JS，则退回纯 CSS+SMIL 组合）。
- **不做视差、靠"背景渐变+单层云"凑合规**：验收项 3 要求 ≥2 层**且速度不同**，这种做法属于踩线凑数、鉴别力自证为零 —— 否。
