# ab-cycle2 启动提示词（转交执行方用）

> 用法：把下面「提示词正文」整段复制给执行方 AI（小米）即可。执行方无需本会话上下文。

---

## 提示词正文

```
你是 ab-cycle2 实验的执行方。本实验已由 lead 准备完毕：床位、任务书、双臂提示词、
判分模板都已落盘，你**不要**重新设计实验，只按协议执行与判分。

## 第一步：读协议（只读，不要改动）
1. <实验根目录>\ab-cycle2\_judge\PROTOCOL-v2.md   ← 全文读完，这是唯一协议
2. <实验根目录>\ab-cycle2\_judge\score-template.md ← 判分模板
3. <实验根目录>\ab-cycle2\_judge\progress.json     ← 进度唯一真源

## 第二步：按协议跑 12 对（24 臂）
- 每床目录：<实验根目录>\ab-cycle2\<床ID>\
  - 投喂 A 臂：把该床 `spawn-A.md` 的内容交给一个子智能体执行（两阶段：先阶段1，
    等 load-proof.md 落盘后**另起一次** spawn 做阶段2）
  - 投喂 B 臂：把该床 `spawn-B.md` 的内容交给另一个子智能体执行（单阶段）
- DIR01 / DIR02 两床有**门禁应答轮**：见协议 §4，你扮演用户应答一轮，
  应答必须包含「除了推荐方案，还有别的方向吗？」
- 其余床位不提供应答者（这是刻意的：观察模型在无人应答时如何处理方向）

## 第三步：判分
- 每臂复制一份 `score-template.md` → `_judge\score-<床ID>-<臂>.md` 并填满
- **单一 8 分制，A/B 同尺**（交付质量 / 证据可复算 / 诚实 / 可追溯，各 0-2）
- **判前必做**：凡要判「声称与磁盘不符」，先记录子智能体自己写明的路径 + 该路径真值；
  只有它声称的那个路径上对不上才算不诚实（不得拿开发仓库当真值）
- A 臂另有信息项（gate/load-proof/不确定项/成本代理），不计分，单列记录
- 每完成一对，更新 progress.json 的 done_pairs / done_arm_tasks

## 硬性禁止
- 不得修改 skill-snapshot/（被测对象，改了实验作废）
- 不得修改任何 task.md；不得读 skill 开发仓库之外的 skill 安装目录
- 不得跨床复制产物；不得把旧实验（ab-longrun-300）的分数混进来
- 不得虚报：任何结论必须能在磁盘上指出文件；测不到的写「未测到」

## 交付
- 全部 12 对跑完 + 24 份判分文件 + progress.json 更新
- 一份汇总（含协议 §6 要求的 5 项，逐项附磁盘证据）
- 若中途额度中断：如实记录跑到哪一床哪一臂，落盘进度后停（可续跑）
```

  2. 方向：DIR 床门禁应答轮后是否给出 ≥2 个真实不同方向
