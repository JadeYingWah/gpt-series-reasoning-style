# notes.md — 几何 / 运动自洽说明（DIR02 · 水母坐热气球 · A 臂）

产物：`art.html`（单文件、内联 SVG、无外部资源）。方向：**C（大胆）「气球驾驶员水母 · 昼夜穿越」**。

---

## 一、坐标系与自适应

- `viewBox="0 0 680 680"`（正方形），`preserveAspectRatio="xMidYMid meet"`。
- 外层 `.stage` 为 `min(100vmin, 860px)` 的正方形并居中（`body{display:grid;place-items:center}`），
  页面背景为深色径向渐变，与夜空同族，因此任意窗口比例下**画面都是居中、完整、不裁切**的**。
- 选用 `meet` 而非 `slice`：`slice` 在 16:9 屏上会把 680 高的画面裁到约 382 可见高度，
  会切掉球囊顶部与触手末端。这是刻意选择，代价是宽屏下左右会露出页面底色。

## 二、层级（z-order，先画在下、后画在上）

```
天空底 rect
├─ 昼/昏/夜/晨 三张全屏渐变层（互相 crossfade）
│   └─ 夜层内含月亮与星群（随夜层一起淡入淡出）
├─ 远景层  p-far   山脊 ×2（0 与 +680）
├─ 中景层  p-mid   云团 ×2
├─ 近景层  p-near  云团 ×2
└─ 载具+主体 .float > .sway
    ├─ 球囊（填色 + 6 条分瓣缝线 + 高光 + 徽记）
    ├─ 吊索 ×4
    ├─ 吊篮内腔
    ├─ 燃烧器 + 火焰
    ├─ 水母（光晕椭圆 → 伞盖 → 护目镜 / 表情）
    ├─ 吊篮前面板 + 编织纹 + 篮口
    ├─ 触手 ×7（伞盖之后画，故垂在吊篮之前，形成"坐在篮里、足须外溢"）
    └─ 缰绳绳 + 黄铜环 ×2
```

关键取舍：三张天空层与月亮/星群在**最底**，载具主体在**最上**，中间夹三层视差——任何视差层都不会遮挡主体。

## 四、视差无缝循环的几何依据

三个视差层的瓦片内容全部落在 `x ∈ [0, 680]`，且**每片复制一份平移到 x+680**（`<use href="#tile" x="680"/>`）。
动画只做 `translateX: 0 → −680`。设位移为 t ∈ [−680, 0]，两片并集的覆盖区间恒为 `[t, 1360+t] ⊇ [0, 680]`，
即 t=0 时覆盖 0..1360、t=−680 时覆盖 −680..680，**边界两端同时闭合**，故循环点无跳变、无空档。

速度差的可见性依据：同为 3 s，远景（20 s 周期）位移 680×3/20 = **102 px**，
近景（7 s 周期）位移 680×3/7 = **291 px**，相差约 2.9 倍——这正是渲染验证里
远景区差异像素 53200、近景区 68358 的来源。

## 五、触手几何自洽

- 伞盖为椭圆穹顶，左缘 x=284、右缘 x=396（宽 112），顶 y=338、下沿基线 y=398，
  下沿用 5 段二次贝塞尔做伞褶（控制点 y=412，实际下垂到约 y=405）。
- 7 条触手的**旋转心严格取在伞盖下沿 y=400 上**，x 依次 296 / 310 / 324 / 340 / 356 / 370 / 384
  （全部落在 284..396 内、且互不重合）。SMIL `type="rotate"` 显式写出旋转中心
  （如 `values="-6 296 400; 6 296 400; -6 296 400"`），因此**不存在 transform-origin 解析歧义**，
  摆动即"绕附着点摆动"，与伞盖下沿不脱开。
- 触手颜色用 `gradientUnits="userSpaceOnUse"` 的竖直渐变（y 390→570），
  与各触手实际长度范围对齐，**越往下越暗**，形成深度提示。

## 六、"清晰可辨 + 朝向一致"（验收第 2 条）的几何/材质依据

1. **纵向分离**：球囊占 y ∈ [52, 336]，伞盖占 y ∈ [338, ~405]，两者**纵向区间不重叠**，
   主体不会被载具"糊"在一起。
2. **材质对立**：球囊＝哑光暖帆布（`radialGradient` #f3cf95→#96562a，硬边、深棕描边、6 条缝线）；
   水母＝半透明荧光（`bellG` 不透明度 .86 + 外发光椭圆 + 柔色描边）。硬边 vs 软边、
   暖橙 vs 冷紫，轮廓与色彩双重区分。
3. **朝向一致**：球囊与水母同处 `.float > .sway` 容器内，共享同一个平移与同一个旋转变换
   （`transform-origin: 340px 240px`），**两者倾角在任何时刻都严格相等**，不可能出现"一个朝左一个朝右"。
4. **徽记不混淆**：球囊上的水母纹样是**扁平线描 + 圆环徽章**（`class="motif"`，opacity 在 0.20↔0.46 之间呼吸），
   与主体"有体积、有护目镜、有触手"的实体形象刻意区分——只做呼应，不做第二个水母。

## 七、已知的视觉取舍（非缺陷，但记录在案）

- 7 条触手垂在吊篮之前，会遮住吊篮前面板约上半部的编织纹；吊篮的可辨性靠"篮口提手 +
  两侧梯形收口 + 下半部编织纹"维持。这是"足须外溢"这一水母特征的必然代价。
- 火焰底端 y≈328 略低于球囊颈部最低点（y≈336 为颈部中心最低），火焰绘制在球囊之后，
  故看起来是"从颈部开口冒入球囊"，未做真正的开口挖除。
- 缰绳黄铜环（y=512）固定不动，而穿过它的两条长触手在摆动，二者会有 ~几 px 的相对滑移。
