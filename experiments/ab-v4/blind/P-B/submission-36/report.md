## 3. 检测方法与阈值判定依据

4 条机制上独立的路径，全量合并取并集：

| 路径 | 机制 | 参数 | 检出点数 |
|---|---|---|---|
| A 全局鲁棒 z | (x − 全局中位数)/(1.4826·MAD)，捕获全局极端离群 | 阈值 5.0 | 693 |
| B 滚动中位数残差 | 6h 居中窗（72 点）滚动中位数 + 局部 IQR 尺度，对状态漂移鲁棒 | 阈值 4.5 | 6 |
| C 季节-趋势残差 | 自实现分解：288 点日周期趋势（滚动中位数）+ 按时刻分组的季节中位数，残差全局 MADz | 阈值 4.5 | 1337 |
| D 一阶差分鲁棒 z | Δx 的全局 MADz，捕获突变沿（尖峰起点/阶跃） | 阈值 6.0 | 14 |

**阈值依据**： (A) MAD-z 阈值 5.0 高于经典 Iglewicz-Hoaglin 建议（3.5），因本序列左尾天然厚重（低温工况真实存在），取 5.0 控制全局路径误报；(B)(C) 取 4.5（约 4.5σ，安全场景留有敏感裕量）；(D) 差分噪声尖峭取 6.0。所有阈值未经标注数据调优（任务禁止读标注），判定依据为鲁棒统计惯例 + 变异测试敏感性验证（见 §5）。

**合并规则**：检出点间隔 ≤6 行（30 分钟）归入同一区间——尖峰前兆与主崩溃属同一事件；边界外扩 ±2 行（10 分钟）——保守度调节，宁可错报不可漏报。全量合并覆盖 2260 点（占序列 9.96%）。

## 4. 数据质量说明

- 22695 行 × 2 列（timestamp, value），采样间隔 300 秒（中位数），无 NaN；
- **时间戳回绕缺陷**：第 10149 行起 11 行时间戳回跳（2014-01-07 02:55 → 02:00 重复段），属数据自身特性；检测按行序处理，报告时间一律取数据文件原值，不做时间排序修正（该区段值平稳 ~94，不影响任何检出区间）；
- 值域 [2.08, 108.51]，中位数 89.41，MAD 尺度 2.51。

## 6. 不确定项与局限

1. **阈值未对标标注**：按任务边界禁止读取标注文件，阈值依据鲁棒统计惯例与变异测试设定，未做精确率-召回率调优（UNVERIFIED：对官方标注的命中/误报率未知）；
2. **路径 C 对长时漂移存在盲区**：日周期季节中位数会被 >1 天的持续偏移部分"吸收"（如 2014-02-07~09 失效窗口 C 未独立命中，由 A/D 覆盖）——这正是采用多路径并集而非单路径的原因；
3. **区间 #1（2013-12-02 21:15）**位于序列起点，滚动/季节统计在边缘不完整，高置信判定含边缘伪影嫌疑，保留在全量报告中（宁可错报）；
4. **单点尖峰区间的持续时间**：如 108.51、105.59 等单点尖峰，前后各外扩 10 分钟为报告边界，实际尖峰持续时间 ≤1 个采样点（5 分钟）；
5. statsmodels STL 因本机 Python 3.14 兼容问题不可用，路径 C 为 pandas 自实现季节分解（机制等效，已在证据脚本中自包含验证）。
