# Test-Bed 4：复杂创意任务双臂对照实验

## 任务描述
用SVG画明日方舟终末地角色佩里卡骑自行车的2D动画，要求最高质量水平。

## 实验设计
- **A臂（带skill）**：加载 gpt-series-reasoning-style
- **B臂（裸模型）**：名义上不加载skill
- 两臂在空目录里从零开始

## 实验污染说明

**注意：本次实验设计有污染。**

名义上B臂是裸模型，但实际上：
- B臂执行者之前的会话里加载过旧版skill
- 所以B臂也知道那套纪律——也会做验证、列未验证项

也就是说：**两个臂都知道skill的内容，不是真正的对照。**

## 执行者评分

两个执行者都打了 **7.5/10**。

### 一致结论：
1. **真打开看一眼最有用**——抓到代码审查抓不到的视觉bug
2. **规划面对创作型任务空转**——一半规则对视觉产物没用
3. **7条里2-3条是死重**——变异测试、数字重算对视觉产物没地方用
4. **时间账**：验证占35-40%，但净增量只有10-15%

---

## 核心发现

### 最重要的发现：这套纪律学会了就忘不掉

B臂名义上是裸模型，但因为之前知道旧版skill的内容，也会自觉用那套纪律——
做验证、列未验证项、做审计。

**这说明：**
- skill的内容是可传递的——知道了就会用
- 这套纪律是有价值的——一旦知道，就舍不得不用
- 不是"强制你做什么"，而是"让你知道该做什么，然后你自己就会做"

---

## 结论

**虽然实验设计被污染了，但结论反而更硬。**

> 这套纪律一旦被知道，就会自觉被执行。

这就是skill的价值——**不是纪律，是习惯。**
