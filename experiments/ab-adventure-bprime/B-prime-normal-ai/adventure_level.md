# 文本冒险游戏"星际逃生"关卡设计

> 类型：科幻生存 + 分支叙事
> 预计游玩时间：15-20分钟
> 结局数：4个
> 参考：2026互动叙事设计最佳实践、有意义选择设计原则

---

## 一、故事背景

2187年，你是"曙光号"货运飞船的机械师。一次超空间跳跃失败后，飞船坠落在未知星球的轨道上。生命维持系统正在失效，你必须在氧气耗尽前找到逃生方法。

**核心冲突**：生存 vs 道德选择——是独自逃生，还是冒险拯救被困的船员？

---

## 二、状态系统

### 资源状态

| 状态 | 初始值 | 说明 |
|---|---|---|
| 氧气 | 45分钟 | 每分钟消耗1分钟，某些操作消耗更多 |
| 生命值 | 100 | 受伤会减少，归零则游戏结束 |
| 工具 | 基础工具包 | 可收集更多工具 |
| 盟友 | 0 | 拯救的船员数量 |

### 关键选择标记

- `found_crew`：是否发现被困船员
- `repaired_ship`：是否修复了飞船通讯
- `took_oxygen`：是否拿走了应急氧气
- `sacrificed_self`：是否选择自我牺牲

---

## 三、场景与分支

### 场景1：苏醒（起点）

你在休眠舱中醒来，警报声刺耳。飞船正在漏气。

**选择**：
1. **检查飞船状态** → 场景2（了解情况，消耗2分钟氧气）
2. **直接找逃生舱** → 场景3（快速但信息不足，消耗1分钟氧气）

---

### 场景2：飞船控制室

你来到控制室，发现飞船严重受损。通讯系统离线，生命维持系统只能维持45分钟。

**发现**：船员名单显示有3人在休眠舱中，但休眠舱受损，他们无法自行苏醒。

**选择**：
1. **修复通讯系统** → 场景4（消耗10分钟氧气，需要工具）
2. **去休眠舱查看船员** → 场景5（消耗5分钟氧气）
3. **直接去逃生舱** → 场景3（消耗3分钟氧气）

---

### 场景3：逃生舱

你找到了逃生舱，但只有一个座位。启动需要密码，而密码在船长的个人终端里。

**选择**：
1. **回去找密码** → 场景2（消耗3分钟氧气）
2. **尝试破解密码** → 场景6（消耗5分钟氧气，50%成功率）
3. **放弃逃生舱，寻找其他方法** → 场景7（消耗5分钟氧气）

---

### 场景4：通讯修复

你花了10分钟修复了通讯系统，接收到了微弱的求救信号——附近有救援队，但需要30分钟才能到达。

**选择**：
1. **等待救援** → 结局A（如果氧气足够）
2. **去休眠舱救船员** → 场景5（消耗5分钟氧气）
3. **独自去逃生舱** → 场景3（消耗3分钟氧气）

---

### 场景5：休眠舱

你找到了3名被困船员，他们的休眠舱正在缓慢失压。要救他们需要打开舱门，但这会消耗大量氧气。

**选择**：
1. **打开舱门救他们** → 场景8（消耗15分钟氧气，获得3个盟友）
2. **留下他们，自己逃生** → 场景3（消耗3分钟氧气，`found_crew=true`）
3. **尝试远程唤醒** → 场景9（消耗8分钟氧气，30%成功率）

---

### 场景6：密码破解

你尝试破解逃生舱密码...

**结果**（随机）：
- **成功**（50%）→ 结局B（独自逃生）
- **失败**（50%）→ 场景3（消耗5分钟氧气，系统锁定10分钟）

---

### 场景7：寻找其他方法

你在飞船货舱找到了一艘小型维修艇，但燃料只够一个人飞行到附近的空间站。

**选择**：
1. **独自驾驶维修艇离开** → 结局C（独自逃生）
2. **回去救船员一起走** → 场景5（消耗5分钟氧气）
3. **用维修艇发送求救信号** → 场景4（消耗10分钟氧气）

---

### 场景8：拯救船员

你打开了休眠舱，3名船员苏醒。他们感谢你，但氧气消耗加快了。

**选择**：
1. **一起去逃生舱** → 场景10（消耗5分钟氧气，但逃生舱只有1个座位）
2. **一起去维修艇** → 场景11（消耗5分钟氧气，维修艇只能坐1人）
3. **等待救援** → 结局A（如果氧气足够，4人一起获救）

---

### 场景9：远程唤醒（可选）

你尝试远程唤醒船员...

**结果**（随机）：
- **成功**（30%）→ 场景8（船员苏醒，消耗8分钟氧气）
- **失败**（70%）→ 场景5（休眠舱进一步受损，必须手动打开）

---

### 场景10：逃生舱困境

你和3名船员来到逃生舱，但只有1个座位。

**选择**：
1. **让一名船员坐逃生舱** → 结局D（你留下，其他人想办法）
2. **自己坐逃生舱离开** → 结局B（独自逃生，带着愧疚）
3. **放弃逃生舱，一起找其他方法** → 场景11（消耗3分钟氧气）

---

### 场景11：维修艇困境

你和船员来到维修艇，但只能坐1人。

**选择**：
1. **让一名船员驾驶维修艇求救** → 结局A（救援队到达，全员获救）
2. **自己驾驶维修艇离开** → 结局C（独自逃生）
3. **一起等待救援** → 结局A（如果氧气足够）

---

## 四、结局系统

### 结局A：全员获救（好结局）
**条件**：修复通讯或发送求救信号 + 氧气足够 + 等待救援
**描述**：救援队及时到达，你和所有船员安全获救。你被授予英雄勋章。

### 结局B：独自逃生（中性结局）
**条件**：成功破解密码或选择自己坐逃生舱
**描述**：你独自逃生，但船员们的命运未知。余生中，你时常想起他们。

### 结局C：维修艇逃生（中性结局）
**条件**：选择独自驾驶维修艇
**描述**：你驾驶维修艇到达空间站，安全生还。但飞船上的其他人...

### 结局D：自我牺牲（悲壮结局）
**条件**：让船员坐逃生舱或维修艇，自己留下
**描述**：你把生存机会让给了船员。在氧气耗尽前，你看到逃生舱成功发射。

### 隐藏结局：窒息（坏结局）
**条件**：氧气耗尽
**描述**：氧气越来越稀薄...你的意识逐渐模糊。

## 五、设计要点

### 有意义选择原则
每个选择至少改变以下一项：
1. **故事位置**：到达不同场景
2. **资源状态**：氧气、生命值、工具变化
3. **盟友数量**：拯救或放弃船员
4. **未来解读**：同一结局因选择不同而有不同感受

### 延迟后果
- 场景1选择"直接找逃生舱"→ 场景3发现需要密码 → 必须回去（浪费时间）
- 场景5选择"留下船员"→ 结局B/C带有愧疚感
- 场景4修复通讯 → 解锁结局A的可能性

### 时间压力
- 氧气持续消耗，制造紧迫感
- 某些选择消耗更多氧气（打开舱门15分钟，修复通讯10分钟）
- 氧气耗尽触发坏结局

### 重玩价值
- 4个主要结局 + 1个隐藏结局
- 随机元素（密码破解、远程唤醒）增加变数
- 不同选择路径导致不同的结局感受

## 六、分支流程图

```
苏醒
├── 检查状态 → 控制室
│   ├── 修复通讯 → [等待救援→结局A] [救船员→休眠舱] [逃生舱→逃生舱]
│   ├── 救船员 → 休眠舱
│   │   ├── 打开舱门 → 拯救船员
│   │   │   ├── 逃生舱 → [让船员→结局D] [自己→结局B] [一起→维修艇]
│   │   │   └── 维修艇 → [让船员→结局A] [自己→结局C] [等待→结局A]
│   │   ├── 留下船员 → 逃生舱 → [破解→结局B/失败] [找密码→控制室]
│   │   └── 远程唤醒 → [成功→拯救船员] [失败→休眠舱]
│   └── 逃生舱 → 逃生舱
└── 直接逃生舱 → 逃生舱
    ├── 找密码 → 控制室
    ├── 破解密码 → [成功→结局B] [失败→逃生舱]
    └── 其他方法 → 货舱
        ├── 独自离开 → 结局C
        ├── 救船员 → 休眠舱
        └── 发信号 → 控制室
```

## 七、平衡调整

### 氧气消耗平衡
- 最短路径（独自逃生）：约15-20分钟
- 救人路径：约25-35分钟
- 全员获救：需要30分钟+（修复通讯+等待）
- 初始45分钟，所有路径都可行，但容错空间不同

### 选择权重
- 好结局需要更多努力（修复通讯+救人+等待）
- 中性结局较容易（独自逃生）
- 坏结局是时间管理失败的惩罚
