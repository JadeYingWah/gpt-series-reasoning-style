# 任务：设计并实现一个「城市天气时光机」交互式网页

请设计并实现一个单文件 HTML 网页，展示一个城市 24 小时的天气变化。用户可以通过拖动时间滑块，查看不同时刻的天气状态。

## 功能要求

1. **单文件交付**：所有 HTML/CSS/JS 内联在一个 .html 文件中，可直接在浏览器打开运行，不依赖外部 CDN 或 API
2. **时间滑块**：用户可拖动 0:00–24:00 的时间滑块，页面随时间变化
3. **至少 3 种天气状态**：例如晴、雨、雪、多云、雾等，每种有 distinct 的视觉表现
4. **动态过渡**：时间变化时，天空颜色、光照效果、天气粒子（雨滴/雪花/阳光）要有平滑过渡动画
5. **信息展示**：显示当前时刻的温度、湿度、风速等关键气象信息
6. **城市元素**：包含城市剪影或地标建筑，随时间/天气有光影变化

## 设计要求

- 视觉风格自选，但必须有明确、统一的设计主题
- 动画流畅，不卡顿
- 信息层次清晰，关键数据一眼可读
- 代码结构清晰，有适当注释

## 加分方向（非必须，做到了更好）

- 昼夜交替的完整光影循环（日出/日落/正午/午夜）
- 天气状态之间的过渡动画（不是瞬间切换）
- 交互细节（hover 效果、点击反馈、音效等）
- 独特的视觉创意（如像素风、水彩风、赛博朋克、极简等）

## 交付

- 一个可直接运行的 .html 文件
- 简要说明你的设计思路和实现要点（几句话即可）
