# 游戏道具"能量核心"3D建模技术规范

> 道具类型：科幻风格可收集道具
> 目标平台：PC/主机游戏
> 参考：2026游戏3D资产制作标准、PBR工作流最佳实践

---

## 一、设计概述

**能量核心（Energy Core）** 是游戏中的关键收集道具，为玩家提供能量补给和技能解锁。设计风格：科幻水晶+机械底座，发光效果突出能量感。

**设计要点**：
- 水晶部分：不规则多面体，内部发光
- 底座部分：金属机械结构，固定水晶
- 装饰环：可旋转的能量环，增加动态感
- 整体比例：高约15cm，直径约10cm

## 二、拓扑规范

### 多边形预算

| 部件 | 目标面数 | 说明 |
|---|---|---|
| 水晶 | 200-300面 | 不规则多面体，不需要过多细节 |
| 底座 | 300-400面 | 机械结构，需要足够的倒角 |
| 装饰环 | 100-150面 | 圆柱形，分段适中 |
| 总计 | 600-850面 | 低多边形风格，适合实时渲染 |

### 拓扑原则

1. **四边形为主**：主要结构使用四边形，便于细分和编辑
2. **三角形可接受**：平面区域和不可变形区域可使用三角形
3. **避免N-gon**：变形区域和需要平滑的区域不使用五边形以上
4. **边环走向**：机械结构的边环应跟随轮廓线
5. **无重叠面**：所有表面不得重叠
6. **无隐藏面**：删除内部不可见面，优化性能

### 倒角要求

- 所有硬边需要倒角（至少2段）
- 倒角大小：0.5-2mm（根据道具比例）
- 尖锐边缘保留硬边标记

## 三、UV展开规范

### UV布局

| 部件 | UV空间占比 | 说明 |
|---|---|---|
| 水晶 | 40% | 发光效果需要高分辨率 |
| 底座 | 40% | 金属细节需要清晰 |
| 装饰环 | 20% | 重复纹理，可降低分辨率 |

### UV规则

1. **UV岛间距**：至少4像素（2048贴图下）
2. **无重叠**：需要独立烘焙的部件UV不重叠
3. **方向一致**：纹理方向保持一致（向上为Y+）
4. **对称利用**：对称部件可镜像UV，节省空间
5. **Texel密度**：统一为10.24 px/cm（2048贴图）
6. **棋盘格检查**：使用棋盘格验证无拉伸

## 四、PBR材质规范

### 材质列表

| 部件 | 材质类型 | Base Color | Roughness | Metallic |
|---|---|---|---|---|
| 水晶 | 半透明发光体 | #7C3AED（紫色） | 0.1 | 0.0 |
| 底座 | 拉丝金属 | #4A5568（深灰） | 0.4 | 0.9 |
| 装饰环 | 亮面金属 | #F59E0B（金色） | 0.2 | 1.0 |

### PBR参数要求

1. **Base Color**：
   - 金属：50-240 sRGB（避免纯黑纯白）
   - 非金属：30-240 sRGB
   - 不含烘焙光照信息

2. **Roughness**：
   - 0.0（完全光滑）到1.0（完全粗糙）
   - 金属表面：0.1-0.4
   - 非金属表面：0.3-0.8

3. **Metallic**：
   - 金属：1.0
   - 非金属：0.0
   - 过渡区域：0.0-1.0渐变（如氧化、磨损）

4. **Normal Map**：
   - 切线空间法线
   - 8位或16位精度
   -  DirectX格式（Y-）

5. **Emissive**：
   - 水晶部分使用自发光
   - 强度：2.0-5.0（HDR）
   - 颜色：与Base Color一致但更亮

### 贴图分辨率

| 贴图类型 | 分辨率 | 格式 |
|---|---|---|
| Base Color | 2048×2048 | PNG/TGA |
| Normal | 2048×2048 | PNG/TGA |
| ORM (Occlusion/Roughness/Metallic) | 2048×2048 | PNG/TGA |
| Emissive | 1024×1024 | PNG/TGA |

## 五、LOD规范

| LOD级别 | 面数 | 距离 | 用途 |
|---|---|---|---|
| LOD0 | 600-850 | 0-5m | 近景，完整细节 |
| LOD1 | 300-400 | 5-15m | 中景，减少细节 |
| LOD2 | 100-150 | 15-30m | 远景，仅保留轮廓 |
| LOD3 | 50-80 | 30m+ | 极远景，最简形状 |

### LOD切换原则

- 切换距离根据实际游戏场景调整
- 切换时避免明显的" popping"
- LOD之间保持轮廓一致

## 六、导出规范

### 文件格式

| 用途 | 格式 | 说明 |
|---|---|---|
| 游戏引擎 | FBX | 包含网格、UV、材质槽 |
| 通用交换 | OBJ | 仅网格和UV |
| 高模烘焙 | FBX/OBJ | 高多边形版本 |

### 导出设置

- 坐标系：Y-up（或根据引擎要求）
- 单位：厘米
- 缩放：1.0（不缩放导出）
- 三角化：导出时自动三角化
- 平滑组：导出硬边/平滑组信息

### 命名规范

```
SM_EnergyCore        // 静态网格
SM_EnergyCore_LOD1   // LOD1
SM_EnergyCore_LOD2   // LOD2
T_EnergyCore_BC      // Base Color
T_EnergyCore_N       // Normal
T_EnergyCore_ORM     // Occlusion/Roughness/Metallic
T_EnergyCore_E       // Emissive
M_EnergyCore         // 材质实例
```
