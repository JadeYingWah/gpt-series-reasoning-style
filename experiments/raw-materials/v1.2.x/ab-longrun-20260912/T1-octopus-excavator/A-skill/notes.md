# 几何与运动自洽说明 · 章鱼开挖掘机

对应文件：`excavator.html`（单文件，无外部依赖）

## 1. 履带循环速度与车速关系

无滑移接地条件下，履带花纹相对车身的水平平移速度 **必须等于** 车辆对地速度 \(v\)。

| 量 | 符号 | 本文件取值 | 单位 |
|---|---|---|---|
| 车辆对地速度（基线） | \(V_0\) | 90 | px/s |
| 驱动轮有效半径 | \(r\) | 18 | px |
| 驱动轮角速度 | \(\omega\) | \(\omega = V_0 / r = 5.0\) | rad/s |
| 履带相位推进 | \(\Delta\phi\) | \(\phi \mathrel{+}= v \cdot dt\) | px |

实现约束（`frame()` 内）：

```js
trackPhase += v * dt;                       // 履带相位按真实车速推进
sprocketAngle = trackPhase / R_SPROCKET;    // ω = v/r，恒等式，不是独立动画
```

- 履带板（pad）水平位置由 `trackPhase` 驱动，速度恒等于 \(v\)。
- 驱动轮/诱导轮辐条旋转角 = `sprocketAngle`，与履带同一运动学链。
- 加速（Space / 点击）时 \(v\) 缓动上升，履带与轮同步变快——不会出现「轮快带慢」。

**可验算**：1 秒后 `trackPhase` 增加 90px；若换 60fps，则每帧 `+1.5px`。`omega = 90/18 = 5 rad/s ≈ 0.796 rev/s`。

## 2. 章鱼腕足与机械臂相对运动

两者使用 **非公度频率**，不会锁相。

| 运动 | 角频率 | 周期 |
|---|---|---|
| 腕足波（5 条） | \(W_{wave} = 2.2\) rad/s | ≈ 2.86 s |
| 液压挖掘循环 | \(\omega_{dig} = 2\pi / 3.7\) ≈ 1.70 rad/s | 3.7 s |
| 拍频 | \(\lvert 2.2 - 1.70\rvert = 0.50\) rad/s | ≈ 12.6 s |

- 第 \(i\) 条腕足：\(\phi_i = t \cdot 2.2 + i \cdot 0.85\)，另有二次谐波 \(1.7\times\) 频。
- 5 条可见腕足：左卷、撑玻璃、握操纵杆、推油门、前伸指路——基向/长度/振幅各不相同。
- 液压臂：分段缓动（外伸→铲土→抬臂→卸土回程），非纯正弦，与腕足波形也不同。
- **结论**：腕足与机械臂相位差随时间漂移，不存在固定比例锁死。

## 3. 背景视差（≥2 层）

| 层 | 内容 | 系数 \(P_k\) | 速度 \(S_k = v \cdot P_k\) |
|---|---|---|---|
| L0 | 天空 / 日落光晕 / 星（静态） | — | 0 |
| L1 | 远景工业天际线 | 0.12 | ≈ 10.8 px/s |
| L2 | 中景塔吊 / 集装箱 / 雾带 | 0.35 | ≈ 31.5 px/s |
| 地面 | 泥土纹理 / 油渍 | 1.00 | = v |
| L3 | 近景碎石 / 杂草 / 尘粒 | 0.70 | ≈ 63 px/s |
| L4 | 前景钢梁 / 吊链 | 1.20 | ≈ 108 px/s |

相机跟车：车身锚在 x≈620，世界向左卷；层速度差产生深度。

## 4. 风格约束

- **非**白底扁平通用卡通风：墨色黄昏天空、琥珀施工灯、锈迹钢结构、油膜水洼、胶片颗粒+暗角。
- 章鱼特征：外套膜、双侧眼、喙、安全帽、5 条带吸盘腕足。
- 挖掘机特征：履带底盘、驾驶舱、配重、排气、动臂/斗杆/铲斗 + 液压缸、斗齿。

## 5. 交互

| 操作 | 效果 |
|---|---|
| Space / 点击按住 | 加速（×1.55），履带/轮/视差同步变快 |
| ← / → | 目标车速 20–200 px/s |
| D | 挖掘循环速率切换（1× / 2×），腕足频率不变 → 相对运动更明显 |
