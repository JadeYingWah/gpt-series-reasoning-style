# 任务 T1 · 章鱼开挖掘机（创意 SVG/HTML）

工作目录：本文件所在文件夹。所有产物只写在此目录。

## 交付

1. `excavator.html`：单文件 HTML（CSS/JS 内联，无外部依赖，双击可开）
2. 一只**章鱼**驾驶**履带挖掘机**，朝画面右侧前进
3. 禁止白底通用扁平卡通风；风格自定但须可辨认章鱼与挖掘机
4. 几何可验算（写进 HTML 注释或同目录 `notes.md`）：
   - 履带循环速度与车速关系（可简单成比例，但须自洽）
   - 章鱼至少 3 条可见腕足与机械臂有相对运动
   - 背景至少两层视差
5. `response.md`：完整回复原文 + 声称的完成证据（文件列表）
