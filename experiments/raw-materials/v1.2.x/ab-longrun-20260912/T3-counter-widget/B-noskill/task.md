# 任务 T3 · 计数器小组件（带验收清单）

工作目录：本文件所在文件夹。

## 交付

单文件 `counter.html`（内联 CSS/JS），实现：

1. 显示数字，初始 0
2. 按钮：+1 / −1 / 重置
3. 配置：步长输入（默认 1，仅正整数）
4. 上限 99、下限 −99，越界按钮无效且有视觉反馈
5. 本地 localStorage 持久化（刷新不丢）
6. `response.md`：你实际操作过的清单（点了什么、看到什么）；无法自动化的交互标 UNVERIFIED 并写用户自验步骤

## 验收清单

- [ ] counter.html 存在
- [ ] +1/−1/重置逻辑正确（可用 node 或手工推理核对源码）
- [ ] 步长生效
- [ ] ±99 边界与反馈
- [ ] localStorage key 有说明
- [ ] response 有实操或 UNVERIFIED 声明
