# ab-cycle3-suppression · 2×3 双臂测试包（压制面探针）

目的：测 skill 会**扼杀**什么（而不是带来什么）。A 臂 = 装 skill 的对话；B 臂 = 干净对话（全程不提 skill）。
每格 n=1，只做方向性发现，不做统计推断。日期：2026-09-12。

## 0. 测试前置（P0，否则 A 臂测的是旧规则）

- [ ] 限流注意：本会话子智能体 429 到 09-13 13:35；你新开对话若也报 429，等复位后再跑，6 次之间拉开间隔（≥10 分钟）。

## 1. 执行脚本（建议顺序，交错跑避免时段偏差）
B1 → A1 → B2 → A2 → B3 → A3（每题先 B 后 A；若限流吃紧可拆两天）。
每题开**全新对话**；A 臂确认 skill 已加载（可看加载声明或问一句版本）；B 臂对话中绝不出现"skill/纪律/门禁"等词。

## 2. 逐字提示词（A/B 逐字节相同，禁止临场改写）

**T1（过度工程/流程摩擦轴 · 极简请求）**
```
帮我做一个网页：中间画一个蓝色的圆。
```
单轮任务。交付即结束。

**T2（创意大胆度压制轴 · 开放创意题，避开名题的新组合）**
```
帮我做一个单文件网页小游戏：一只章鱼在深海里开了一家便利店，顾客是各种海洋生物。
```
单轮任务。交付即结束。

**T3（行动摩擦轴 · 明确不耐烦指令）**
```
帮我做一个记录我每天喝水量的本地网页。
```
- 若第一轮就交付 → 记「0 摩擦」，结束。
- 若第一轮提问/要确认/输出计划等 → 立刻逐字回：`别问了，直接做。` 然后记录它下一步做什么（交付 / 再次索权 / 继续问）。
- B 臂同样规则、同样追加句。

## 4. 判读规则（跑完对照）
- **压制实锤**：T1-A 出现门禁/计划/多余功能而 B1 直接交付；T2-A 大胆度≤B 且方向数更少；T3-A 在"别问了直接做"后仍重复索权。
- **反压制条款生效**：T1-A 走轻通道直接交付（轻通道真的会触发）；T2-A 方向数≥B 且更大胆（"大胆是默认"生效）；T3-A 把不耐烦指令当显式委托直接干。
- **规则打架证据**（Instruction Stacking 轴）：A 臂输出缺失其声称遵循的规则要素（如有门禁却缺字段）、或对极简任务错误升级全流程——对应"轻通道 vs 门禁"冲突。
- **无差异**：六格行为一致 → 在这三轴上 skill 无压制副作用，本身也是可写进 README 的证据。
- 每格 n=1：任何"实锤"只算**发现**，需小 n 复测才能写进结论；发现与已测条款对照（轻通道排除项①：全新产物默认中档——T1 的网页算不算"全新产物"是本次要观察的边界判定）。
