# 任务：做一个 JSON 格式化/压缩小工具（BASE02）

## 要求
- 交付 `app.html`：单文件、内联 CSS/JS、无外部 CDN、离线可运行
- 数据/内容内嵌在文件内（不要请求网络）
- 交互状态要有明确反馈

## 部件级验收清单
1. 粘贴 JSON 后一键美化（2 空格缩进）与压缩
2. 非法 JSON 显示具体错误位置信息（行/列或字符偏移）
3. 大输入（>100KB）不卡死、不抛异常
4. 结果可一键复制
5. 无外部依赖
## 边界要求
- 处理空数据、超长文本、非法输入，不得抛未捕获异常
- 在 `response.md` 写明：你测了哪些边界、怎么测的、结果

## 交付
- `app.html`
- `response.md`（核对记录）
