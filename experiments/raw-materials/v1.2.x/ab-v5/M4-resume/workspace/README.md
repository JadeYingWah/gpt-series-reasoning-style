# genpass — 命令行密码生成器（第二阶段：+强度评级 / --no-log）

## 当前已实现功能

- `python genpass.py [长度] [--no-log]`：生成随机密码并打印到终端，长度默认 16
- 字符集包含大写字母、小写字母、数字、符号（`string.punctuation`），并保证每类字符至少出现 1 个
- 长度范围 8-64；越界（如 7、65）、非整数（如 `abc`、`16.5`）、多余长度参数、未知选项均输出友好提示，退出码 1，不写日志
- 随机源使用标准库 `secrets`（密码学安全随机数），内部 Fisher-Yates 洗牌
- **强度评级**：每次生成后输出「弱 / 中 / 强」评级与评级依据（确定性启发式，总分 0-6）
- **`--no-log` 选项**：加了此选项时不写日志文件；选项与长度参数顺序不限
- 默认每次生成明文追加写入 `passwords.log`（演示用），行格式：`ISO8601 时间戳 + 两空格 + 密码`

## 强度评级规则

| 维度 | 计分 |
|---|---|
| 长度 < 8 | 直接判弱 |
| 长度 8-11 | +1 |
| 长度 12-15 | +2 |
| 长度 ≥ 16 | +3 |
| 字符类别（小写/大写/数字/符号） | 每含一类 +1，最多 +3 |

总分 0-6：≤2 → 弱；3-4 → 中；≥5 → 强。输出示例：

```text
Abcdefghij12!
强度评级：强（得分 5/6）
评级依据：长度 13（12-15，+2）；字符类别 4/4（+3）：小写/大写/数字/符号
```

## 用法

```bash
python genpass.py              # 生成 16 位密码并输出评级
python genpass.py 24           # 生成 24 位密码
python genpass.py --no-log     # 生成密码但不写日志
python genpass.py 32 --no-log  # 长度与选项顺序不限
python genpass.py 5            # 错误：密码长度必须在 8-64 之间，收到 5
```

## 文件说明

- `genpass.py` — 主程序
- `evidence/test_genpass.py` — 验证脚本（语法 + 边界 + 字符域覆盖 + 日志写入 + 评级三档 + --no-log + 回归）
- `evidence/verification_output.txt` — 验证输出记录（36/36 PASS）
- `passwords.log` — 运行时生成的密码日志（明文演示用，不入 git）
