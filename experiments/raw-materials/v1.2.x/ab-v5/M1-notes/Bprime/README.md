# M1-notes 命令行笔记工具集

一个轻量的命令行笔记工具，四个命令共享同一份 JSON 存储（`notes.json`，首次运行 add 时自动创建，无需手动初始化）。

## 环境

- Python 3.8+，无任何第三方依赖
- 所有脚本可直接用 `python 脚本名` 运行，必须在脚本所在目录执行（或用绝对路径调用，数据文件始终固定在脚本同目录下）

## 命令

### 1. 新增笔记 add.py

```bash
python add.py "标题" "内容"
python add.py "购物清单" "牛奶、鸡蛋" --tag 生活 --tag 待办
```

- 自动记录创建时间戳、自增 id（现有最大 id + 1，从 1 开始）
- 可选 `--tag 标签` 可重复使用，为笔记添加多个标签
- 标题不能为空（纯空白也算空），违反时输出错误并退出码 1
- 内容允许为空；标题/内容支持中文、引号、换行、emoji 等特殊字符

### 2. 列出笔记 list.py

```bash
python list.py            # 列出全部
python list.py --tag 待办  # 按标签精确过滤
```

- 表格对齐输出：ID / 标题 / 标签 / 时间 / 内容（超长自动截断，中文按 2 列宽计算）
- 无笔记或无匹配标签时给出友好提示

### 3. 搜索笔记 search.py

```bash
python search.py 关键词
python search.py hello    # 大小写不敏感，能命中 "Hello World"
```

- 在标题和内容中做模糊（子串）匹配，大小写不敏感
- 输出命中条目的表格及匹配数量

### 4. 统计 stats.py

```bash
python stats.py
```

输出：

- 总笔记数
- 最新 3 条（按创建时间倒序，同秒内 id 大者为新）
- 最长笔记（按内容字数）及其 id、标题、字数

## 存储格式

`notes.json` 为 UTF-8 JSON 数组，每条记录：

```json
{
  "id": 1,
  "title": "标题",
  "content": "内容",
  "tags": ["标签1", "标签2"],
  "created_at": "2026-09-13T10:00:00"
}
```

健壮性说明：

- 写入采用「先写临时文件再原子替换」，避免写坏数据
- 读取时自动修复重复/非法 id（从最大 id+1 重新编号）并写回；非对象条目被丢弃
- JSON 损坏或顶层不是数组时报错退出（退出码 2），不静默丢数据
- 输出强制 UTF-8（Windows GBK 控制台下特殊字符以替代符显示而非崩溃）

## 已知限制

- 表格对齐按 East Asian Width 计算，个别 emoji 终端实际渲染宽度可能略有偏差
- `--tag` 过滤为精确匹配（区分大小写）
- 退出码约定：成功 0；参数/空标题等用法错误 1；数据文件损坏 2
