## 6. 决策记录

1. **字段前后空格**: 按 RFC 4180 保留为字段内容（`a, b ,c` → `['a',' b ','c']`），与 stdlib csv 一致；未做裁剪。
2. **未闭合引号 / 闭合后多余字符**: 严格模式抛 ValueError（含字段位置上下文）。**已知分歧**: stdlib csv 对二者宽容接受（实测 `'"a'` → `[['a']]`、`'"a"b'` → `[['ab']]`）。任务书要求「必须处理」未规定行为，选严格语义（fail-fast，错误信息明确），差分对照中已排除该分歧。
3. **空行语义**: 空行 → `[]`；`""`（引号包裹空字段）→ `['']`；末尾换行不产生多余空行；文件 `"\n"` → `[[]]`。均与 stdlib csv 实测一致。
4. **BOM 双层处理**: bytes 检测 `EF BB BF` 后跳过；str 剥离开头 `\ufeff`。
5. **CLI**: 逐行 print 解析结果（Python list repr）；退出码 0 成功 / 1 文件或解析错误 / 2 用法错误。
6. **非引号字段内引号**（如 `a"b"c`）: 按字面字符处理，与 stdlib csv 一致。
