# 创意类任务 A/B 实验报告

## 实验设计
- 任务：为虚构独立游戏写完整营销文案包（概念介绍+Steam文案+社媒推广+预告片脚本）
- 任务类型：纯创意类
- 三个臂：
  - **B 臂**：无 skill（基线）
  - **A2 臂**：精简流程（轻量配置）
  - **A1 臂**：全流程（中档配置，含网络搜索行业最佳实践+2轮循环审查）

## 关键发现

### 1. 创意类任务中，轻量配置(A2)性价比仍然最高
- 质量提升：4.8 → 6.8（+42%）
- 成本增加：1x → 2.7x（+170%）
- 核心增量：差异化定位、多平台适配、分镜表
- 适合：大多数创意类任务

### 2. 全流程(A1)对创意类的增量价值不如代码类
- 代码类 A2→A1：6.3 → 8.8（+2.5分）
- 创意类 A2→A1：6.8 → 8.6（+1.8分）
- 原因：创意类任务的循环审查价值有限（第1轮验证字符数，第2轮基本是确认）；实操验证模块对创意类无效
- 全流程的核心增量来自网络搜索（行业最佳实践），而非流程本身

### 3. 创意类任务的全流程可以精简
- 循环审查：2轮→1轮足够（创意无法自动化验证，第2轮价值低）
- 实操验证：创意类不需要（无法自动化验证创意效果）
- 网络搜索：应聚焦"行业最佳实践"而非"技术方案"
- 建议：为创意类任务单独配置"创意全流程"（比通用全流程轻30%）

### 4. 创意类任务的核心价值是"结构化"而非"流程化"
- B臂的问题不是创意不好，而是没有结构（想到什么写什么）
- A2/A1的价值在于提供了结构化框架（概念→Steam→社媒→预告片→Slogan→受众）
- 模块化选择矩阵对创意类的最大贡献是"确保不遗漏部分"，而非"提升创意质量"

## 对模块化选择矩阵的调整建议

### 创意类任务专属配置
1. **轻量配置**：保持不变（加载证明+门禁+证据报告）
2. **中等配置**：增加"行业最佳实践搜索"为必选，循环审查从2轮→1轮
3. **全流程配置**：去掉"实操验证"模块，循环审查从2轮→1轮
4. **新增"创意结构化检查"**：替代实操验证，检查是否遗漏关键部分（概念/文案/推广/脚本等）

### 通用调整
1. 任务类型判断后，应根据类型自动调整流程模块（创意类去掉实操验证，代码类保留）
2. 循环审查轮数应按任务类型配置：代码类2轮，创意类1轮，数据类2轮

## 实验局限
- 单任务样本（n=1），结论需更多创意任务验证
- 质量评分为主观评分，存在偏差
- 未测试"纯创意"（如写诗、画画提示词）与"创意+实用"（如营销文案）的差异
- token 消耗为估算值，非精确计量
