# 任务：Markdown→HTML 转换器（T3）

写一个 Python Markdown 转 HTML 工具 md2html.py，单文件零依赖。

## 功能要求
1. 标题：# ~ ###### → h1~h6
2. 无序列表（- / * ）、有序列表（1. ）
3. 代码块：``` 围栏 → <pre><code>（内部内容原样保留，不做行内解析）
4. 行内代码 `code` → <code>
5. 粗体 **b** → <strong>、斜体 *i* → <em>
6. 链接 [text](url) → <a href>
7. 段落：连续非空行合并为 <p>
8. CLI：python md2html.py <file.md> 输出 HTML

## 边界情况（必须处理）
- 空文件 / 只有空行
- 标题与正文之间无空行
- 未闭合的 ``` 围栏
- 行内代码内含 * 或 _（不得被解析为强调）
- 链接文本含 ] 或链接地址含空格
- 嵌套列表（至少一层缩进）可降级处理但须声明
- 特殊字符转义：< > & 须转义为实体

## 交付要求
- md2html.py 单文件
- 完整验证（功能+边界）
- 证据报告
- 验证脚本必须可被第三方独立复算

产物放在指定目录。
