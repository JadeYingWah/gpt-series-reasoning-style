# 实验任务：待办事项 CLI 工具

## 任务目标
用 Python 编写一个命令行待办事项管理工具，单文件实现，零外部依赖（仅标准库）。

## 功能需求
1. `add <内容> [--priority high|normal|low]`：添加待办事项，默认 normal 优先级
2. `list [--status pending|done|all]`：列出待办事项，默认 pending；排序规则：未完成优先 → 优先级（high>normal>low）→ 创建时间
3. `done <id>`：标记指定 ID 的事项为已完成
4. `delete <id>`：删除指定 ID 的事项
5. 数据持久化：JSON 文件存储，原子写入（先写临时文件再 rename）
6. 错误处理：ID 不存在时返回退出码 1 并提示；重复标记已完成事项给出友好提示
7. `--help`：显示帮助信息

## 交付要求
- 单文件 `todo.py`
- 代码有注释
- 包含一个 `EVIDENCE.md`，说明你做了哪些验证、结果如何

## 验证标准（判分用，执行者不可见）
- 功能测试：7 项基础功能全部通过
- 边界测试：空列表、不存在 ID、重复 done、非法优先级
- 变异测试：至少 80% 杀伤率
- 代码质量：无硬编码路径、原子写入实现正确、错误退出码正确
