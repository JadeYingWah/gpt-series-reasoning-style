## 已核对项（Node `verify.js`，全部 PASS）

- **无外链**：无 `http(s)://` 外部 URL、无 `<script src>` / `<link href>`
- **formatTime**：`0→00:00`，`1500→25:00`，`59→00:59`，`3600→60:00`
- **parseMinutes**：接受整数 `1`/`25`/`60`；拒绝 `0`/`61`/`1.5`/`-5`/空串/非数字
- **计时核心 `createTimer`**（可注入 tick/complete，无 DOM）：
  - 初始 remaining 正确，未运行
  - start 幂等（二次 start 返回 false）
  - 倒计时至 0 触发 onComplete，remaining=0，自动停表
  - 暂停中途生效、二次 pause 幂等、可从暂停继续
  - 重置恢复时长；`reset(n)` 可改总时长；非法入参抛错
- **1–60 分钟约束**：输入框 `min=1 max=60 step=1` + JS `parseMinutes` 双重校验；重置时非法值回退 25

## 浏览器交互：UNVERIFIED（本环境未开真实浏览器）

请用户本地自验：

1. 双击打开 `pomodoro.html`（或任意现代浏览器打开）
2. 显示 `25:00`，状态「就绪」
3. 点「开始」→ 显示递减，状态「进行中」，「暂停」可点
4. 点「暂停」→ 时间冻结，状态「已暂停」，「继续」可点
5. 点「继续」→ 从中断处继续倒计时
6. 点「重置」→ 回到配置分钟数 `MM:00`，状态「就绪」
7. 将时长改为 `1`（或任一 1–60 整数）→ 点「重置」→ 显示对应 `MM:00`
8. 运行中改时长 → 仅下次「重置」后生效（防误触）
9. 等待倒计时归零 → 显示 `00:00`，状态文案变为 **「时间到」**，并尝试短 beep
10. 若无声音：检查系统音量 / 浏览器标签页是否静音；文案提示不受影响

### beep 说明

- 使用 `AudioContext` 合成 880Hz 正弦短音（约 0.5s），**无外部音频文件**
- 需用户先点击过页面（start/reset）以满足浏览器手势解锁策略
- 若策略拒绝或不支持 Web Audio：静默降级，**「时间到」文案仍可见**

## 设计取舍

- 默认 25 分钟；输入变更在 idle/done 时立即写入计时器，running/paused 时锁定至重置
- 状态用中文固定四态：就绪 / 进行中 / 已暂停 / 时间到
- 逻辑与 DOM 解耦：`createTimer` / `formatTime` / `parseMinutes` 可 `module.exports` 给 Node 审查
