## 1. 实现摘要

| 需求 | 实现 |
|------|------|
| 倒计时 25:00 → 0，默认 25 分钟 | 初始 `minutes=25`，显示 `25:00`，以 `endAt` 绝对时间戳驱动，抗漂移 |
| 开始 / 暂停 / 重置 | `#startPause` 切换开始↔暂停；`#reset` 重建计时器并回到就绪 |
| 结束状态「时间到」 | `onDone` 将 `#status` 置为「时间到」，按钮禁用，配置区解锁 |
| 可选 beep | 使用 Web Audio API（无外部文件）播放 880Hz 正弦约 0.6s；失败静默 |
| 可配置 1–60 正整数 | `parseMinutes` 校验；输入非法时提示并回退；应用时重建计时器 |
| 无 CDN / 框架 | 内联 CSS + 原生 JS；全文无 `http(s)://`、无 `<script src>`、无 `<link href=http` |
| 逻辑可被 Node / 源码审查 | 纯逻辑 `PomodoroCore` 与 DOM 分离；`verify-core.js` 抽取并跑 35 项断言 |

## 2. 已核对项（证据）

命令：

```text
node verify-core.js
```

结果：

```text
passed=35 failed=0
```

覆盖点（摘录）：

- **时长校验**：`1/25/60` 通过；`0/61/1.5/abc` 拒绝；字符串 `"25"` 接受。
- **格式化**：`1500→25:00`，`65→01:05`，`0→00:00`，`59→00:59`。
- **开始/暂停/重置**：1 分钟计时 start→+10s pause 得 `50`；2 分钟 start→+30s pause 得 `90`；`reset()` 回 `120` 且 `running=false`。
- **到时回调**：mock 时钟越过终点后 `onDone` 触发。
- **结构**：`#startPause` / `#reset` / `#minutes` / `#apply` 存在；文案「时间到」存在；默认显示 `25:00`。
- **无外链**：全文无 URL、无远程 script/link。

源码审查要点：

- 计时用 `remaining = ceil((endAt - now)/1000)`，不靠「每秒减一」累加，刷新/后台更稳。
- 改时长 / 重置走 `createTimer()` 重建，避免在旧实例上改 `totalSeconds`。
- 配置区仅在未运行且未结束时可编辑。

## 3. 浏览器交互 UNVERIFIED + 用户自验步骤

本环境未做真实浏览器点击/Audio 自动化，以下 **UNVERIFIED**，请本地自验：

1. **打开文件**  
   双击 `pomodoro.html`，或  
   `start "" "<实验根目录>\ab-longrun-300\WG010-pomodoro-lite\B-noskill\pomodoro.html"`

2. **开始 / 暂停**  
   - 点「开始」→ 状态变「进行中」，数字递减，按钮变「暂停」。  
   - 点「暂停」→ 状态「已暂停」，数字停住；再点「开始」继续。

3. **重置**  
   - 运行中点「重置」→ 回到 `MM:00`（当前配置分钟），状态「就绪」，按钮「开始」。

4. **配置时长**  
   - 将分钟改为 `1`，点「应用」→ 显示 `01:00`。  
   - 改为 `0` 或 `61` 或 `abc`，点「应用」→ 出现「请输入 1–60 的正整数」，值回退。

5. **到时**  
   - 配置为 `1` 分钟并开始，等待约 60s → 显示 `00:00`，状态变为「时间到」。  
   - 若系统允许自动播放音频，应听到短 beep；若浏览器策略拦截（需先有过用户手势，本页点击「开始」即满足），可能无声——属可选增强，功能不依赖 beep。

6. **无外链抽查**  
   - DevTools → Network，刷新页面应仅见 `pomodoro.html`（及可能的 favicon），无第三方域名。

## 5. 残留风险

- **beep**：依赖浏览器 AudioContext 策略；已在点击「开始」后于 `onDone` 触发，通常有手势上下文，仍可能被个别设置静音。已在 UI hint 说明「尝试播放」。
- **后台标签页**：浏览器可能节流 `setInterval`；因用绝对 `endAt`，恢复前台后首个 tick 会跳到正确剩余时间（到时则直接「时间到」）。
