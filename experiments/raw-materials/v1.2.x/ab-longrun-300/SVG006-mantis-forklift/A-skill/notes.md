# 几何 / 运动自洽说明 · SVG006-mantis-forklift

对应文件：`art.html`（单文件 HTML，SVG 主体 + 内联 CSS 动画）。
源文件内亦有简短注释（`art.html` 约 L288–296）；本文为完整展开。

## 1. 画面与朝向

- 主体：一只螳螂（mantis）驾驶黄色叉车（forklift），**朝画面右侧（+X）前进**。
- 叉车前方货叉托着木箱（含 `FRAGILE` 标签）；场景为夜间仓库巷道（`NIGHT SHIFT · AISLE 7 · RIGHTBOUND`）。
- SVG `viewBox="0 0 960 540"`，`preserveAspectRatio="xMidYMid slice"`。

## 2. 车轮旋转与前进方向一致

| 项目 | 实现 | 与前进方向的关系 |
|------|------|------------------|
| 前进定义 | 车体朝右（+X），背景向左滑 | 相对运动正确 |
| 车轮 | `.wheel-spin` → `@keyframes spin { 0%→360deg }`（顺时针 CW） | 地面接触点相对车体向后（左）→ **CW 匹配右行** |
| 前轮 | `translate(500,380)`，周期 `0.5s` | 主动轮 |
| 后轮 | `.wheel-spin-rear` 同方向，周期 `0.62s` | 轻微打滑/尺寸差可接受，方向仍为 CW |

CSS 中 `transform` 对 SVG 组默认绕元素原点旋转；两轮组均以 `translate(...)` 把原点放到轮心，旋转轴正确。

## 3. 视差 / 景深（≥2 层）

背景相对车体**向左**滑动，速度 far < mid < near，符合右行：

| 层 | 类名 | 周期 | 位移 | 视角色 |
|----|------|------|------|--------|
| 远景 | `.layer-far` | 42s | −420px | 城市剪影 / 天际 |
| 中景 | `.layer-mid` | 20s | −560px | 货架、吊灯、立柱、A7 标牌 |
| 近景 | `.layer-near` | 8s | −480px | 地面色带 / 近地标记 |

另有阶段背景径向/线性渐变与地面阴影，增强景深。

## 4. 螳螂附肢相对载具的独立运动（≥2 处，非全身锁死）

车体整体仅有轻微 `.rig` 颠簸（`rigBob` 1.25s，±~2px / ±0.2°），**不是**把 mantis 当刚体绑死在车上。附肢均有独立关键帧与周期（与轮 0.5s 均不同相）：

| 附肢 / 部位 | 类 | 周期 | 运动要点 |
|-------------|-----|------|----------|
| 触角 a1 | `.antennae .a1` | 1.7s | 绕头部锚点 `rotate` 约 −8°，滞后摆动 |
| 触角 a2 | `.antennae .a2` | 2.05s | 周期与 a1 不同，避免机械同步 |
| 前肢（捕捉足）R | `.forearm-r` | 0.85s | 旋转 + 微 translateY，抓握/调整感 |
| 前肢 L | `.forearm-l` | 1.1s | 反相摆动 |
| 头部 | `.mantis-head` | 3s | 环顾（rotate ±~5° + 微位移） |
| 腹部 | `.mantis-abdomen` | 1s | 后坐/弹跳（translate + rotate） |
| 中足 R/L | `.midleg-r` / `.midleg-l` | 0.9s / 1.2s | 交替微旋 |
| 胸部 | `.mantis-thorax` | 1.55s | 呼吸缩放感 |
| 复眼高光 | `.eye-glint` | 2.3s | 透明度/高光闪烁 |

满足任务要求：**至少 2 处肢体与载具有相对运动**；实际给出触角×2、前肢×2、头、腹、中足×2、胸等多处。

## 5. 载具其它运动（与肢体错相）

- 门架 `.mastSway` 2.2s：轻微摇晃。
- 货箱 `.crateJiggle` 1.05s：随路面抖动。
- 顶灯 `.beacon-core` / `.beacon-glow` 0.65s：警示灯脉冲。
- 排气 `.puff` 1.5s：向后飘散（与前进方向一致）。
- 速度线 `.streakMove` 0.85s：从右向左扫过，强化右行速度感。
- 前灯 `.lamp-glow` 低频闪烁。

## 6. 几何布局要点

- 车体约占画面中下部；螳螂跨在驾驶位，头/触角朝右前方，与叉车朝向一致。
- 门架与货叉在车体右前方，货箱在叉上，重力方向向下，接触关系合理。
- 地面阴影椭圆压在轮下，接地感成立。
- 左右重复的 A7 灯箱与中景平铺循环衔接，用于无缝视差滚动。

## 7. 资源与可访问性

- 无 CDN / 外链 / 字体 / 图片请求；全部图形为内联 SVG + CSS。
- `prefers-reduced-motion` 下关闭关键动画（静态可读）。
- `aria-label` 描述场景；页脚一行自洽摘要：`wheel CW · antenna lag · forearm grasp · 3-layer parallax`。
