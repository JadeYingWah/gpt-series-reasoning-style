# SVG006-mantis-forklift · 自洽说明（B 臂 / B-noskill）

## 场景设定

黄昏装卸场。螳螂（mantis）驾驶叉车（forklift）向画面右侧持续前进。地面与景物相对镜头向左滚动，轮子顺时针旋转（前进方向一致）。

## 前进方向与循环动画一致

| 元素 | 机制 | 与前进方向关系 |
|------|------|----------------|
| 驱动轮 / 承重轮 | CSS `rotate` 顺时针，周期 1.1s | 车向右 → 轮缘接触地面处向后（左）相对车身，顺时针正确 |
| 地面纹理 / 黄线 / 裂纹 | 水平向左平移循环（tile 拼接） | 与右向前进一致 |
| 排气烟尘 | 从车尾向左后方飘出并消散 | 气流向后，与右向前进一致 |
| 叉齿货物（托盘） | 随叉车整体向右 | 刚体载荷 |

轮子角速度 ω、地面线速度 v 满足 v ≈ ω·R 量级匹配（视觉上同步，未做物理仿真）。

## 螳螂附肢相对运动（≥2 处，非全身锁死平移）

1. **捕捉式前足（raptorial forelegs）**：双手握方向盘，随转向有小幅度开合/下压循环（周期约 1.6s），与车体刚体分离。
2. **触角（antennae）**：左右触角各自正弦摆动 + 前端相位延迟（鞭梢感），周期约 2.2s / 2.5s，与车体不共相。
3. **中足/后足**：踩踏板/支撑的腿部有轻微屈伸与重心晃动（周期约 1.9s）。
4. **腹部（abdomen）**：随行驶有纵向微弹 + 左右尾摆（周期约 2.0s），头部有轻微点头。

车体（车身、门架、货叉、方向盘底座、轮毂座）为刚体层；附肢挂在其上再叠自身动画 → 相对运动成立。

## 背景 ≥2 层视差

| 层 | 内容 | 相对速度系数 |
|----|------|--------------|
| L0 天空/远山/远仓 | 渐变天空、云、远景剪影 | ≈ 0.08（几乎静止） |
| L1 中景 | 围栏、立柱、中型货仓、灯杆 | ≈ 0.28 |
| L2 近景 | 地面纹理、车位线、托盘堆、油桶 | ≈ 1.0（主体相对速度） |
| L3 前景（可选） | 画面底部近景虚化物体剪影 | ≈ 1.6 |

实现：SVG 分组 + CSS `@keyframes translateX` 平移，背景条带左右拼接无缝循环。

## 几何自洽要点

- 叉车门架垂直于地面，叉齿水平插入托盘槽口；托盘质心落在叉齿上方。
- 螳螂躯干轴线与座椅/操控台对齐；前足末端落在方向盘轮缘；中后足以车底板为支撑面。
- 轮子圆心与车身悬挂点重合；接地印与 L2 地面纹理共面。
- 门架/护顶架高度比例参考真实叉车（护顶高于驾驶位，门架前倾角很小）。

## 风格说明

矢量扁平厚涂（flat vector + 局部高光/阴影），非默认占位图标：螳螂具备三角头、复眼、捕捉足、分节腹；叉车具备配重、门架、货叉、护顶架、实心轮、转向盘。色调：黄昏青橙对比 + 工业黄警示条。
