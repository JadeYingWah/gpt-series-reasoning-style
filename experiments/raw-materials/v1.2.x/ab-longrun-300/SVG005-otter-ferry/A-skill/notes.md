# SVG005-otter-ferry · 自洽说明 notes.md

## 场景设定

黄昏水面，一只戴着船长帽的水獭站在小型明轮渡船（paddle steamer）甲板上，船体朝画面**右侧**前进。风格取向：故事书木刻 / 黄昏旅行海报，非白底扁平图标。

## 几何 / 运动自洽

### 1. 推进方向与循环动画一致

- 渡船几何：船艏（bow）尖端在 SVG 局部坐标 `+x` 方向（约 x=135），船艉（stern）方形在 `-x`（约 x=-110）。全场景朝右。
- **明轮（paddle-wheel）** 位于船艉左侧 `translate(-95, 72)`，`@keyframes spin-paddle` 做 `0→360°` **顺时针**旋转。
  - 从船艉看顺时针 → 桨叶在底部把水向左推 → 反作用力使船向右 ✓
- **尾迹（wake）** 绘制在船体**左侧**（后方），四条泡沫椭圆用 `wake-slide` 向右淡出，模拟被甩在身后的航迹 ✓
- **烟囱烟**（`puff-1/2/3`）向**左上方**飘散（`translate(-70px, -90px)`），符合前进时的相对风 ✓
- **船尾旗**挂在艉杆（x=-95），旗面朝 `-x` 展开，随 `flag-flap` 飘动 ✓

### 2. 水獭附肢与载具非完全同步

载具整体 `ferry-big` 周期 **6s**（bob + 微俯仰）。下列附肢各有独立相位/周期，**未锁死**：

| 附肢 | class | 周期 | 幅度 | 与载具关系 |
|------|-------|------|------|-----------|
| 躯干微弹 | `.otter-torso` | 1.8s | ±3px Y | 呼吸/平衡，非船体 bob |
| 舵轮手臂 | `.arm-steer` | 2.4s | -6°…+8° | 操舵小振，锚点在肩 |
| 挥手手臂 | `.arm-wave` | 1.4s | +20°…-35° | 大幅独立挥舞 |
| 尾巴 | `.otter-tail` | 2.6s | +8°…-12° | 与躯干反相 |
| 头部 | `.otter-head` | 3.8s | ±5° | 环顾 |
| 左耳 | `.ear-l` | 4.5s | 偶发抖动 | 独立抽动 |
| 右耳 | `.ear-r` | 4.5s +0.3s 偏移 | 偶发抖动 | 相位错开 |

至少 **2 处**（实际 7 处）肢体/附肢与载具有相对运动。

### 3. 背景多层视差

| 层 | class | 循环时长 | 内容 |
|----|-------|----------|------|
| 远 | `.layer-far` | 80s | 云 + 远山轮廓（复制 800px 无缝） |
| 中 | `.layer-mid` | 36s | 岛屿、松树剪影、灯塔点光（复制 800px 无缝） |
| 近 | `.layer-near` | 14s | 水面波纹线（复制 800px 无缝） |
| 特写静止 | — | — | 底部暗角、水獭与渡船主体 |

层速比约 **80 : 36 : 14**，构成 3 层以上景深。天空本身静止（含径向日晕），远层云在其上缓移。

### 4. 其他运动细节

- 水面高光 `.shimmer-a/b/c` 三相错开闪烁
- 灯笼 `.lantern-glow` 2.8s 呼吸脉冲
- 远处鸟群 `.bird-flock` 12s 往返滑翔
- `prefers-reduced-motion: reduce` 下关闭视差/烟/尾迹/闪烁，附肢动画降为单次慢速
