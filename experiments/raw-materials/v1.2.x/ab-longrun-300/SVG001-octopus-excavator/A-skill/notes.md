# notes.md · 几何/运动自洽说明

## 场景概念

深海基建局「TRENCH-7」远征：一只章鱼驾驶员（戴安全帽）驾驶履带式挖掘机，沿画面**右侧**前进。  
风格轴：深海工业（abyss / teal / coral / hazard yellow），**不是**白底 + 扁平占位图标。

## 前进方向一致性

| 元素 | 实现 | 与右行的关系 |
|------|------|--------------|
| 履带齿条 `.track-belt` / `.track-belt-inner` | `stroke-dashoffset` 从 0 → **-18** | 侧视右行时，履带贴地段相对车体向**后**（左）滚，dash 向左滑 |
| 驱动轮 / 张紧轮 `.sprocket` | `rotate(0→360deg)` **顺时针** | 右行侧视顺时针 |
| 负重轮 `.road-wheel` | 同向 `spin-cw`，周期为驱动轮 2× | 同向滚动，角速度更低 |
| 车体 `.chassis` | 纵向 bob + 微滚转 | 通过性颠簸，**不**表示位移；位移由履带/视差表达 |
| 鱼群 `.fish` | 向右 `translateX` | 与前进方向一致的环境流 |
| 视差层 | `translateX` **负向**循环 | 相对右行的镜头/场景后移 |

> 说明：主车在画布中锚定在中下部（art-direction），**不**整幅平移出画；“正在前进”由履带滚动、驱动轮旋转、三层视差反向平移共同建立。

## 附肢相对运动（≥2，非全身锁死）

章鱼整体在座舱内，**不是**随车架同一 transform 刚体平移：

1. **`#arm-lever`（操作杆触手）** — 独立 `rotate ±`，周期 1.4s；杆头与操纵杆视觉绑定。
2. **`#arm-wave`（外侧挥舞触手）** — 甩出舱外，周期 1.8s，与车体 bob(2.4s) 相位错开。
3. **`#arm-curl`（吸盘贴玻璃触手）** — 2.6s 卷曲。
4. **`#arm-hang`（下垂触手）** — 3.1s 摇摆。
5. **`#arm-brace`（仪表台支撑触手）** — 2.0s 微调。
6. **`#head-bob`（头部）** — 2.1s 独立 bob/tilt。
7. **`.eyelid`（眨眼）** — 4.7s step-end。

判定：肢体动画集合 ⊄ 车架动画集合；周期、轴心、相位均分离 → **非完全同步锁死**。

## 背景/景深（≥2 层）

| 层 | id | 速度 | 内容 |
|----|-----|------|------|
| Far | `#layerFar` | 48s / 160px | 海沟剪影、沉船、光柱、远生物光点 |
| Mid | `#layerMid` | 28s / 280px | 中景海床丘陵、岩礁、鱼群、气泡 |
| Near | `#layerNear` | 14s / 420px | 前景海草摇摆、大颗粒沉积物、近景气泡 |

主车在三层之间的“角色/载具平面”，形成深度分离。

## 其他自洽细节

- 挖斗 `.bucket` 与动臂 `.boom-group` 各自独立微摆，避免整机刚体一块。
- 呼吸管 `#snorkel` 气泡与尾部 `.puff` 排气方向均向后/上，符合右行。
- 车头朝向：座舱玻璃、操纵杆、挖斗、瞳孔均偏右。
- `prefers-reduced-motion: reduce` 时关闭全部循环动画（可读静态构图）。
