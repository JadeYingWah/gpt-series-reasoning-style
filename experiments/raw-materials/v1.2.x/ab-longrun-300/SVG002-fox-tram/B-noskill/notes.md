# notes.md — SVG002-fox-tram · 几何 / 运动自洽说明

## 场景设定

- 画面：黄昏城市有轨电车线（line B）
- 主体：赤狐司机驾驶红色有轨电车，朝 **画面右侧（+X）** 前进
- 画布：1200×700，SVG viewBox，整页 `preserveAspectRatio="xMidYMid slice"`

## 1. 车轮旋转方向与前进方向一致

| 项目 | 取值 |
|------|------|
| 车轮半径 | 28 px |
| 周长 | ≈ 175.9 px |
| CSS `@keyframes spin` | `0deg → 360deg`（屏幕顺时针） |
| 单圈周期 | 0.85 s |
| 隐含线速度 | 175.9 / 0.85 ≈ **207 px/s** |

**方向论证**：车辆在地面朝右滚动时，轮缘相对轮心的接触点向左运动。
屏幕坐标下这对应 **顺时针** 旋转。`spin` 动画为 0→360（顺时针），正确。

四枚车轮均使用相同时长 `0.85s`，轮辐上的参考点（小圆点 `#c0a060`）随旋转，
肉眼可直接判断转向。侧杆（connecting rod）同周期旋转，强化机械联动感。

## 2. Fox 与载具的相对运动（≥2 处，实际 5 处）

载具本体 `.tram-body-bob` 周期 **0.9 s**（垂直微颠簸）。
Fox 的附肢各自独立周期，保证 **非刚体锁死**：

| 附肢 | class | 周期 | 相位偏移 | 说明 |
|------|-------|------|----------|------|
| 左耳 | `.ear-left` | 2.4 s | 0 | 独立抽动，绕耳根旋转 −14°~+6° |
| 右耳 | `.ear-right` | 2.4 s | 0.3 s | 与左耳错相 |
| 双臂 | `.fox-arm` | 1.1 s | L:0.2s / R:0 | 扶方向盘+油门杆，绕肩点摆 ±10° |
| 尾巴 | `.fox-tail` | 1.6 s | 0 | 大幅甩尾 −8°~+18°，在车体外 |
| 头部 | `.fox-head` | 1.1 s | 0 | 垂直 bob ±2 px，与车体 0.9 s 不同拍 |
| 举起的爪 | `.fox-paw` | 2.0 s | 0 | 挥手致意，绕爪根 −25°~+8° |

**判据**：任意两个周期比不是简单整数比（2.4 / 0.9、1.6 / 0.9、2.0 / 0.9、
1.1 / 0.9），长时间不会重新对齐成「全身锁死平移」。

## 3. 背景视差（3 层）

rAF 驱动，虚拟距离 `x` 以 200 px/s 递增；各层按比例反向平移并取模循环：

| 层 | 内容 | 速度系数 | 有效 px/s | 循环宽度 |
|----|------|----------|-----------|----------|
| far | 远山轮廓、远距电线杆、灌木 | 0.18 | 36 | 260 px |
| mid | 中景树冠、接触网吊线/支柱 | 0.50 | 100 | 270 px |
| near | 轨道床、枕木、近景杂草 | 1.00 | 200 | 400 px |

near 层速度 **200 px/s** 与车轮隐含线速度 **207 px/s** 误差约 3%，
轨道纹理与轮缘表观速度基本同步（肉眼不可分辨差异）。

另：蒸汽从烟囱冒出后向 **左后方** 飘散（与前进方向相反），作第四重运动暗示。
运动线条（motion lines）拖在车尾左侧。

## 4. 无外部资源

- 单文件 HTML，CSS / JS 全部内联
- 无 CDN、无 `@import`、无 `fetch`、无 `<img src="http…">`
- 字体仅使用系统族：`Arial, sans-serif`、`Georgia, serif`
- 全部图形为 SVG 原语 + gradient / pattern / filter，由浏览器本地渲染

## 5. 风格说明

非「白底 + 默认扁平占位图标」。采用：

- 黄昏天空三段渐变（深紫 → 玫红 → 琥珀）+ 弯月 + 低垂日晕
- 剪影式远中景（山、树、电线杆、接触网）
- 有轨电车：奶油色车顶、红色车身腰线、湖蓝色车窗反光、车头灯柔光、
  车顶受电弓 + 接触火花、蒸汽烟囱
- Fox：渐变橙毛、深色耳内绒、浅色吻部与胸腹、司机马甲与金徽章、
  司机帽、黑亮圆眼高光、白色尾尖、肉垫细节
- 全场景 `softGlow` / `puffBlur` 滤镜做柔和辉光
