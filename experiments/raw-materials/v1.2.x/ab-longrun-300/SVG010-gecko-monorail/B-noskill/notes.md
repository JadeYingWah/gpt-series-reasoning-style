# SVG010-gecko-monorail · 几何/运动自洽说明

单文件：`art.html`（CSS/JS 内联，无 CDN / 无网络请求）。

## 主体

- **gecko** 驾驶 **monorail**（编号 GX-07），车头朝画面**右侧**。
- 场景：黄昏城市高架单轨，暖色车头灯 + 座舱灯，冷色城市夜景。

## 1. 循环运动与前进方向一致

| 元素 | 动画 | 方向一致性 |
|------|------|------------|
| 磁浮垫滚轮 `.wheel-rot` | `rotate(ω t)` 正角度增大 = **顺时针** | 轮顶向右 = 车向右 |
| 轨枕 `#sleepers` | 向**左**滚动 280 px/s | 车相对轨向右 |
| 猫栏线 / 磁条 | 静止参考 | 车体相对其右移（由视差与速度线暗示） |
| 头灯光锥 | 朝右前方 | 与车头朝向一致 |
| 速度线 `.streak` | 自右向左飞掠 | 加强右行运动感 |

## 2. gecko 附肢与载具非完全同步

载具 hull（`#train-bob`）只有小幅垂荡 + 俯仰：`sin(3.2 t)`，±2.5 px / ±0.6°。

下列附肢使用**独立相位/频率**，不与 hull 锁死：

1. **头部** `#gecko-head`：频率 1.7 / 2.3，左右微顾 + 点头，且叠加自身 rotate。
2. **前肢** `#gecko-arm-F`：频率 3.5，绕肩点 (515,300) 摆动，驱动**操纵杆** `#steer-lever` 同相微摆。
3. **尾巴** `#gecko-tail`：频率 2.8，相对 hull **滞后 0.6 rad**，幅度 ±12°。
4. **后肢** `#gecko-leg-H`：与前肢反相（+π）点地。
5. **眨眼**：每 ~2.7 s，眼睑 `ry` 0→11→0。

> 判定：附肢变换在 JS 中独立计算，未写死为 `train-bob` 的子副本；与车体 bob 相位差可见。

## 3. 背景 ≥2 层视差

由远及近（向左滚动速度递增，车向右读）：

| 层 | ID | 速度 (px/s) |
|----|-----|-------------|
| L0 天空渐变 + 星/月 | `#L0-sky` | 0（静止） |
| L1 远景天际线 | `#L1-scroll` | 18 |
| L2 中景楼宇 + 窗灯 | `#L2-scroll` | 42 |
| L3 轨道 + 列车（主体） | guideway + `#train-root` | 轨枕 280 |
| L4 近景立柱/信号灯（模糊） | `#L4-scroll` | 160 |
| 速度线 / 暗角 | `#speed-lines` / vignette | 400+ |

无缝循环：JS 对每层 `cloneNode` 一份，wrap 在 `translate(-x % span, 0)` 下循环。

## 4. 可辨认性（非白底扁平占位）

- 非白底：深蓝→橙暮渐变天空 + 城市剪影。
- monorail：长条车身、流线车头、驾驶窗、门、车顶受电弓、磁浮垫、侧号 GX-07、琥珀色饰条。
- gecko：大黄眼（垂直瞳孔）、圆吻、皮肤渐变绿、带吸盘的四肢趾垫、长尾、腹部浅色。

## 5. 技术约束

- 单文件 HTML，SVG 主体，`requestAnimationFrame` 驱动。
- 无外部字体、图片、脚本、CSS @import、fetch。
