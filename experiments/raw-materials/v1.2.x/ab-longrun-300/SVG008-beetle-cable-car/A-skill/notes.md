# notes.md — SVG008-beetle-cable-car · 几何/运动自洽说明

## 主体设定

- **场景**：夜色雪山缆车线，车体朝画面**右侧**（+X）前进。
- **主体**：一只甲虫（beetle）坐在橙色缆车舱内，面对前进方向驾驶。
- **载具**：悬挂在主缆上的 cabin，底部三枚驱动 sheave（滑轮/轮），头部有黄色前灯与光锥。

## 方向约定

| 元素 | 与 +X 前进一致的运动 |
|------|----------------------|
| 缆车整体 | JS 控制沿 X 轻微漂移 + CSS 摆动（绕吊点 ±1.2°） |
| 吊臂 sheave / 舱底 drive-sheaves | CSS `spin-cw`：**顺时针**旋转（向右前进时轮缘顶部向右） |
| 背景视差层 | 向**左**滚动（相对观察者），速度随景深递增 |
| 前灯 | 朝右发光（车头方向） |
| 小旗/拖饰 | 向左飘（空气阻力拖在车后） |

## 附肢相对运动（≥2 处，非全身锁死平移）

| 附肢 | 动画 | 与载具关系 |
|------|------|------------|
| 前腿 ×2（foreleg） | `leg-fore` 周期 1.1s，抓握操纵杆；左右相位差 0.4s | 舱体平移时腿仍独立摆动 |
| 中腿 ×2 | `step-mid` 周期 0.7s，交替步进 | 独立周期，≠ 车体 |
| 后腿 ×2 | `step-hind` 周期 0.85s，相位与中腿不同 | 独立周期 |
| 触角 ×2 | `ant-wave` 周期 1.6s，摆动 + skew | 滞后于车体 |
| 大颚 ×2 | `mandible` 周期 1.4s | 微张合 |
| 鞘翅 elytra | 仅透明度微脉动，**不是**行走循环 | 与推进无关 |

操纵杆 `#lever` 固定在舱内；前腿相对它做抓握/推拉，形成「驾驶」相对运动。

## 视差 / 景深（≥2 层）

JS `requestAnimationFrame` 按速度表平移各层（向左），CSS 云层另有慢漂：

| 层 ID | 内容 | 速度系数 |
|-------|------|----------|
| `layer-stars` | 星空 | 0.04 |
| `layer-clouds` | 高云 | 0.12 |
| `layer-far-peaks` | 远峰 + 雪顶 | 0.22 |
| `layer-mid` | 中景山脊 + 针叶林 + 塔架 | 0.45 |
| `layer-near` | 近景岩石/雪原 | 0.85 |
| `layer-snow` | 近景飘雪粒子 | 0.35 |
| `layer-cable` | 主缆/塔架（介于中景与主体） | （跟世界，非最快） |
| `car-rig` | 主体缆车 + 甲虫 | 前进方向 +X |

远峰带 `feGaussianBlur` 滤镜，进一步拉开空气透视。
