## 协作架构简介

主干默认为**单 Agent 模式**（同一模型内切换规划面、执行面、审查面）。按需可扩展为：

- **子 Agent 增强**：任务适合并行/隔离且宿主支持子 Agent 时启用；启用前须确认子 Agent 能力，未证实则退回主干并标 `UNVERIFIED`。
- **指挥官多 Agent**：需协调独立大模型/Agent 或经用户转交时启用模式三协议（角色身份确认、协调通道确认、完整任务包与闭环）。

形态由 AI 按任务自选并在门禁声明一行理由；用户指名优先、可随时切换。同一任务的不同阶段可混用不同形态。
