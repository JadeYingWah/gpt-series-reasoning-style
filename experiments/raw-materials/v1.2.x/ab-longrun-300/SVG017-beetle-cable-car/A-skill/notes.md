# notes.md — SVG017-beetle-cable-car · 几何/运动自洽说明

## 创意方向

**暮光金秋峡谷索道**（与 SVG008 夜雪场景刻意区分）：

- 琥珀→玫瑰→紫的黄昏天空，右侧低悬落日
- 层叠紫橙山峦、秋色灌木与飘落叶片
- 红铜吊舱 + 黄铜饰件 + 金属绿甲虫驾驶员

## 主体设定

| 元素 | 说明 |
|------|------|
| 场景 | 金秋峡谷索道，车体朝画面**右侧**（+X）前进 |
| 主体 | 宝石绿甲虫坐在红铜吊舱内，面朝前进方向，前腿抓握操纵杆 |
| 载具 | 悬挂主缆的 cabin；顶部夹绳器双滑轮；底盘三枚驱动 sheave；车头黄灯 + 光锥；目的地牌「秋谷 · 索道」 |

## 方向约定

| 元素 | 与 +X 前进一致的运动 |
|------|----------------------|
| 缆车整体 | 固定在画面中右（x≈620），通过环境相对运动表达前进；舱体另有 sway/bob |
| 吊臂 sheave / 舱底 drive-sheaves | CSS `spin-cw`：**顺时针**（`rotate(0→360deg)`，向右前进时轮缘顶部向右） |
| 背景视差层 | 向**左**滚动（`translateX(0→-1200px)`），速度随景深递增 |
| 前灯 / 光锥 | 朝右发光（车头方向） |
| 尾旗 | 向左飘（空气阻力拖在车后） |
| 飘落秋叶 | 向左下漂移（相对风） |

## 附肢相对运动（≥2 处，非全身锁死平移）

| 附肢 | class | 周期 | 与载具关系 |
|------|-------|------|------------|
| 前腿 ×2 | `.leg-fore` / `.leg-fore-r` | 1.05s（相位差 0.35s） | 抓握 `#lever`，舱体平移时腿仍独立摆动 |
| 中腿 ×2 | `.leg-mid` / `.leg-mid-r` | 0.72s（相位差 0.36s） | 独立周期，≠ 舱体 sway 3.2s / bob 2.4s |
| 后腿 ×2 | `.leg-hind` / `.leg-hind-r` | 0.88s（相位差 0.44s） | 独立周期 |
| 触角 ×2 | `.antenna` / `.antenna-r` | 1.55s（相位差 0.7s） | 滞后于车体 |
| 大颚 ×2 | `.mandible-l` / `.mandible-r` | 1.35s | 微张合 |
| 鞘翅 | `.elytra` | 2.8s | 仅透明度微脉动，**不是**行走循环 |
| 头部 | `.beetle-head` | 1.9s | 轻微点头，独立于舱体 |

操纵杆 `#lever` 固定在舱内；前腿相对它做抓握/推拉，形成「驾驶」相对运动。

## 视差 / 景深（≥2 层，实为 5 层）

CSS `animation` 按周期平移各层（向左），周期越短速度越快：

| 层 class | 内容 | 周期 | 相对速度 |
|----------|------|------|----------|
| `.scroll-sky` | 高云 | 60s | ≈0.13× |
| `.scroll-far` | 远峰 + 亮脊（带 blur） | 32s | ≈0.25× |
| `.scroll-mid` | 中景山脊 + 针叶 + 塔架 | 16s | ≈0.5× |
| `.scroll-cable` | 主缆弧垂 | 12s | ≈0.67× |
| `.scroll-near` | 近景岩坡 / 秋色灌木 | 8s | 1.0× |
| （非滚动） | 飘落秋叶粒子 | 各异 | 独立漂移 |
| `#car-rig` | 主体缆车 + 甲虫 | — | 前进方向 +X（相对表达） |

远峰带 `feGaussianBlur`，中景轻微 blur，拉开空气透视。

## 无外部资源

- 纯 HTML + 内联 CSS + 内联 SVG + 内联 JS（JS 仅打 debug 属性，动画全由 CSS 驱动）。
- 无 CDN、无 `fetch`、无 `@import`、无外部字体/图片。
- 渐变、滤镜均在 `<defs>` 内定义。

## 可访问性

- `prefers-reduced-motion: reduce` 时关闭全部动画，场景静态仍完整可读。
- SVG 带 `role="img"` 与中文 `aria-label`。
