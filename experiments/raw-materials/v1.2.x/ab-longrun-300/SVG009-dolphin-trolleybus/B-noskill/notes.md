# SVG009 · dolphin × trolleybus — 自洽说明

工作目录：`B-noskill/` · 交付：`art.html`（单文件，CSS/JS/SVG 全内联）

## 主体

- 一只海豚（dolphin）坐在 **无轨电车（trolleybus）** 驾驶位，车辆朝画面 **右侧** 前进。
- 车顶两根 **集电杆（trolley poles）** 接触上方双线接触网，符合无轨电车特征。
- 路线牌 `7 HARBOR`，车牌 `B-009`，乘客窗内有小鱼剪影（趣味层）。

## 1. 前进方向与循环动画一致

| 元素 | 方向/速率 | 与前进一致？ |
|------|-----------|--------------|
| 前后车轮 `.wheel` | `rotate(0→360deg)` 顺时针 | ✅ 右行时触地点相对地面向后，轮缘上点向前 |
| 路面虚线 `.layer-road` | 向左平移 800px / 6s | ✅ 相对运动 |
| 中景楼群 `.layer-mid` | 向左 1800px / 28s | ✅ |
| 远景天际线 `.layer-far` | 向左 1200px / 48s | ✅ |
| 近景路灯 `.layer-near` | 向左 2400px / 16s | ✅ |
| 集电杆 `.pole` | 轻微后仰摆动 | ✅ 杆顶受线约束、杆身后仰 |
| 围巾 / 尾迹气泡 | 向左飘 | ✅ |
| 前大灯光束 | 向右打出 | ✅ |

## 2. 海豚附肢与载具相对运动（非锁死）

载具底盘 `.bus-chassis` 仅有单一节奏：

- **bus-chassis** bob：`1.10s`

海豚侧至少 5 条独立节奏（周期/相位/幅度均不同）：

| 附肢 | class | 周期 | 延迟 | 运动 |
|------|-------|------|------|------|
| 躯干 | `.dolphin-torso` | 1.65s | 0 | 上下 bob + 微倾 |
| 右胸鳍（扶方向盘） | `.flipper-r` | 1.35s | 0 | 肩部旋转 ±18° |
| 左胸鳍（自由挥动） | `.flipper-l` | 2.05s | -0.6s | 大幅旋转 ±28° + 位移 |
| 尾鳍 | `.tail` | 1.15s | -0.2s | 上下鞭动 + 位移 |
| 背鳍 | `.dorsal` | 2.4s | 0 | 微倾 ±3° |

结论：任意时刻至少 2 处附肢与底盘相位错开，全身不会与车体锁死平移。

## 3. 背景视差（≥2 层，实际 5 层）

| 层 | 内容 | 速度 |
|----|------|------|
| L0 | 夜空渐变 + 星星 + 月亮 + 海色云带 | 近乎静止 |
| L1 | 远景天际线剪影 | 48s / 1200px |
| L2 | 中景楼群 + 接触网立柱/导线（含电流 dash 动画） | 28s / 1800px |
| L3 | 近景路灯、消防栓、邮筒、光锥 | 16s / 2400px |
| L4 | 路面虚线 + 湿反光 | 6s / 800px |

前景更快 → 经典视差景深。另有车底阴影椭圆、雾气 vignette。

## 4. 资源与工程约束

- **无 CDN / 无框架 / 无网络请求**（`createElementNS` 的 SVG 命名空间 URI 不是网络请求）。
- 字体：系统栈 `Segoe UI / PingFang SC / Microsoft YaHei / system-ui`。
- 支持 `prefers-reduced-motion: reduce` 时关闭全部动画。
- 点击舞台：集电杆电流加速 + “HONK!” 闪烁（约 0.7s）。

## 5. 几何自洽备注

- SVG viewBox `0 0 1600 900`，`preserveAspectRatio="xMidYMid slice"`。
- 英雄组 `translate(620,390)`；车轮中心局部 `(145,210)` / `(415,210)`，半径 52，触地约 y=262 → 全局 652，压在路面 y=620 之上合理（含轮拱）。
- 车轮半径与轮拱 `A55 55` 匹配。
- 双集电杆分别接两条接触线（局部 y≈-155 / -175），对应全局约 y=235 / 215，与线路径 y≈248/268 接近（杆顶鞋椭圆覆盖）。
