## 1. 构图与主题

一只 **owl** 驾驶 **subway**，画面中列车朝 **右侧** 前进。

- 场景：夜间城郊线（NIGHT LINE · OWL-01 · EASTBOUND）
- 主体：两节编组（后车 + 驾驶室车头，车头在右侧 = 前进方向）
- Owl 位于驾驶室大窗内，可见仪表盘、油门杆、身体与羽翼

---

## 2. 几何 / 运动自洽

### 2.1 前进方向 = 画面右侧

| 证据 | 位置 |
|------|------|
| 驾驶室流线型车头在右端 | `#car-cab` path，x 向 780–840 |
| 头灯光束指向右 | headlight beam polygon `848→980` |
| 速度线在车尾（左侧），向左消失 | `#speed-lines` + `speed-dash` translateX 负向 |
| 背景/铁轨整体向左滚动 | 各层 `scroll-*` keyframes 的 `translateX(-800px)` |

### 2.2 车轮旋转与前进一致

- CSS：`.wheel { animation: wheel-spin; }` → `rotate(0deg) → rotate(360deg)`
- 默认为 **顺时针**（clockwise）
- 顺时针旋转 + 地面接触点在下 → 相对车体向右滚 → 与向右前进一致

### 2.3 Owl 附肢相对载具的独立运动（≥2 处）

训练车体仅做 0.55s 竖直微颠（`train-bob`，轨道不平整），**不锁死**肢体。

| 附肢 | 周期 | 轴/形态 | 与车体关系 |
|------|------|---------|------------|
| 左翼 `#owl-wing-l` | 0.70s | 旋转 −8° + 下移 | 周期 ≠ 车体 0.55s；附爪扣油门杆 |
| 右翼 `#owl-wing-r` | 0.70s | 旋转 +6° + 下移（反相） | 同上；附爪扣仪表 |
| 头部 `#owl-head` | 3.20s | 旋转扫描（前视→看仪表） | 周期远长于车体；transform-origin 在颈根 |
| 耳簇 `#tuft-l` / `#tuft-r` | 1.60s | 摆动，左右反相 | 与头、翼、车体均不同步 |
| 眼 `#owl-eyes` | 4.50s | scaleY 眨眼 | 独立 |
| 尾羽 `#owl-tail` | 1.10s | 轻扫 | 独立 |

结论：**至少 5 个独立运动通道**（双翼、头、双耳簇、尾、眼），均与车体 bob 不同相、不同周期，满足「不得全身锁死平移」。

### 2.4 视差分层（≥2 层）

场景深度由 4 层滚动构成（向左滚 = 世界相对向右行驶的列车后移）：

| 层 | 类名 | 时长 | 像素/循环 | 相对速度 | 内容 |
|----|------|------|-----------|----------|------|
| L1 | `.layer-far` | 48s | 800px | 1× | 远景天际线、稀疏窗光 |
| L2 | `.layer-mid` | 24s | 800px | 2× | 中景楼群、站台雨棚「NIGHT」 |
| L3 | `.layer-near` | 12s | 800px | 4× | 近景剪影墙、电杆、接触网、围栏 |
| L4 | `.layer-rail` | 8s | 800px | 6× | 道砟、枕木、钢轨、第三轨 |

速度比 1 : 2 : 4 : 6 近似景深倒数，满足「至少 2 层视差」。

每层用两份 tile（`*-tile-a` / `*-tile-b`，`translate(800,0)`）+ `translateX(-800px)` 循环，实现无缝滚动。

### 2.5 其它自洽细节

- 受电弓 `#pantograph` 在车顶，接触点有微光火花，与中近景接触网高度大致对齐
- 车底阴影椭圆随车体，不随背景滚动
- 头灯 glow 用 `softGlow` filter，光锥朝右

## 3. 实现约束

- 单文件：CSS / SVG / 注释全部内联
- **无** CDN、框架、`@import`、`fetch`、外链图片/字体
- 仅使用系统字体栈 `system-ui, sans-serif`
- 几何全部为内联 SVG 元素；动画全部为 CSS `@keyframes`（无 JS）
