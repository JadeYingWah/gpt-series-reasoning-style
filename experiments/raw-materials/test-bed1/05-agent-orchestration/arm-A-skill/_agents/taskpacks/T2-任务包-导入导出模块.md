## 1. 背景
项目 TaskFlow 是一个 Python 命令行任务管理工具，支持多列表任务的增删改查、JSON 文件持久化。架构与接口已由指挥官设计并冻结（见第 3 节已定决策）。你负责其中**导入导出模块**：让用户能把任务数据在 JSON 与 CSV 两种格式间互转（备份到表格软件、从其他工具迁移数据）。核心模块与 CLI 入口由他人实现，与你无关，你也不要碰。

## 3. 已定决策（不许再议）
1. **语言与版本**：Python 3.13，仅用标准库（`json`、`csv`、`pathlib`、`io` 等），**禁止引入任何第三方依赖**。
2. **模块位置**：`taskflow/io_exchange.py`（单文件模块）。
3. **模块接口（冻结）**——两个公开函数：
   - `export_csv(tasks: list[dict], csv_path: str | Path) -> int`：把任务列表写入 CSV，返回写入行数。列顺序固定：`id,title,list,priority,due,done`。
   - `import_csv(csv_path: str | Path) -> list[dict]`：读 CSV 返回任务字典列表，字段与上表对应。
4. **数据 schema（冻结）**——每个任务字典的字段与类型：
   - `id: str`（UUID 形式字符串）、`title: str`、`list: str`（所属列表名）、`priority: str`（`"high"|"mid"|"low"`）、`due: str | None`（ISO 日期 `YYYY-MM-DD` 或空）、`done: bool`。
5. **编码与格式**：CSV 用 UTF-8（带 BOM，方便 Excel 打开）、逗号分隔、按 RFC 4180 处理引号转义；`done` 在 CSV 中表示为 `"true"/"false"`；`due` 为空时 CSV 单元格留空，导入时空串转 `None`。
6. **目录位置**：所有改动仅限 `taskflow/` 下你自己的交付文件与 `tests/test_io_exchange.py`。

## 4. 完成标准（可核验）
1. `taskflow/io_exchange.py` 实现上述两个冻结接口，函数签名逐字一致。
2. 交付自测文件 `tests/test_io_exchange.py`，用 `pytest` 运行**全部通过**，用例覆盖输入域三段：
   - 正常：往返一致性（export 后 import 得到等价数据）、空列表导出；
   - 边界：title 含逗号/引号/换行、字段缺 `due`、优先级大小写；
   - 异常：CSV 文件不存在、列数不足/损坏行、`priority` 非法值（应抛 `ValueError` 并说明格式）。
3. 交付时给**三句证据**：改了啥 / 怎么验的（给出可复现命令，如 `python -m pytest tests/test_io_exchange.py -v`）/ 哪些没验。
4. 临时文件（中间 CSV 等）不留在交付目录。
