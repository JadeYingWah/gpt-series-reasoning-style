# Design Brief — Neon Void Runner

- **Player promise**: 驾驶霓虹战机在深空航道中闪避陨石并击碎它们，撑过一波波攻势。
- **Target feeling**: 紧张但可控的街机爽感；移动利落，开火有反馈，撞击有代价。
- **Primary verb**: 机动闪避（WASD / 摇杆）。
- **Secondary verbs**: 射击摧毁、冲刺无敌帧躲致命碰撞。
- **Repeat every 5–30s**: 躲一批陨石 → 点掉威胁 → 捡能量/连击得分。
- **What changes across 1–5 min**: 波次提升（密度、速度、小行星体积极值）、分数与护盾压力上升。
- **Lose / learn / restart**: 护盾归零 → 结算画面 → 一键重开（R / 点击），失败可看清撞击来源。
- **Risk / reward**: 贴近大陨石可更快清场但更易撞；冲刺有冷却，乱交会在下一波吃亏。
- **Better player**: 预判弹道、用冲刺穿过密集区、优先打高速小目标。
- **Next decision communicated**: 出生预告方向、护盾条、波次横幅。
- **Non-goals**: 不做开放世界、不做成 AAA 写实、不做付费生成资产。
