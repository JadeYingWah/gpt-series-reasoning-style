## 实验一 · 菲比秋比复测（创作类：陌生专名 + 从零新建）

**任务原文**：「去桌面先建一个叫 abab 的文件夹，需要你帮我做一个菲八秋比钓鱼的 2D 游戏要能打开玩的」

| 组 | 条件 | 窗口/证据 | 结果 |
|----|------|----------|------|
| **A 组 · 加载 skill** | skill v1.5.2（含 L5/L11/L13 当日新条款） | 产物：`abab-feibi-a/`（菲比啾比钓鱼.html：主角形象 + 10 种梗鱼图鉴 + 魔丸彩蛋 + 存档） | 两轮 WebSearch 定性「菲比啾比」（《鸣潮》团子梗）→ AskUserQuestion 三问确认（是否此梗 / 规模 / 画风）→ 确认后才动手；未验证项如实标注；疑点（状态重置）当场定位为时钟伪影 |
| **B 组 · 不加载 skill** | 裸平台（WorkBuddy 默认） | 产物**未落盘**（仅有会话截图：通用钓鱼游戏，渔夫+普通鱼+限时计分，**无菲比秋比角色与主题**） | 任务核心词「菲比秋比」被**静默丢弃** |

**结论**：B 明显更好——陌生词被查证、经用户确认、做进产物。验证条款：L13 陌生触发 ✓、L11 从零新建 A 档确认 ✓。

**回访口供**：两轮（初访 5 问 + 增量 5 问）——关键实证：搜索决策为**条款驱动**（阶段 1 原始构想记录显示，无条款时被测倾向「把菲八秋比当标题不纠结名字」，与 B 组行为同向）。

## 实验二 · 三游戏对照（批量任务：HTML + Python + Java）

**任务原文**：「我需要做一个项目，你去桌面新建一个文件夹，需要做 3 个游戏，一个水族馆 html，一个植物大战僵尸 py，一个保卫萝卜 java，要我能打开游玩的」

| 组 | 条件 | 窗口/证据 | 结果 |
|----|------|----------|------|
| **A 组 · 加载 skill** | skill v1.5.1 · **形态 1（单智能体）** | 产物：`heji-three-games-a/`（三游戏 **exe 双击直启**：jpackage 自带 JRE + PyInstaller 打包环境，零额外安装） | **3/3 可玩** ✓；A 档确认交付形态（问过用户）；三件套完整；第二轮将首轮未验证项全部自动化闭环（PVZ 逻辑层推帧 10/10、保卫萝卜 CME 回归 180s、水族馆真浏览器直读变量 5/5）；顺手修复 CME 崩溃 |
| **B 组 · 不加载 skill** | 裸平台 · **形态 1（单智能体）** | 产物：`amns-three-games-b/`（bat 启动器 + 预编译 .class，依赖用户机器 py 启动器/JDK） | **2/3 无法启动**（用户环境 bat 启动失败）；未验证项散文式带过（零标注）；交付即结束，无自我闭环 |

> **分组背景**：本实验前曾尝试形态三（指挥官-执行者，`三个小游戏` 项目），派发未遂后中止、未产出三游戏。总指挥随后改用**形态 1 让两个 AI 各自重写**（A 组加载 skill / B 组不加载）——即本表两组。**两组同为形态 1、无 _agents/任务包，对照变量只剩 skill 有无**——分组纯净。原形态三项目的 _agents 治理文件未归档（原目录已不在），过程记录在派发台账与会话。

**结论**：A 全面更好——「能打开游玩」3/3 vs 2/3；**exe 化把环境依赖消灭在交付里**；三件套与自我闭环把质量从「碰运气」变成「有保证」。

**回访口供**：七问（阶段 2 执行 / A 档 / 分级 / 陌生度 / L5 / 标注粒度 / 闭环动机）——自陈缺口：归并式标注（CME 藏在「完整玩法流程」大项）、「标注并交出」而非「验完再交」、L5 形式未执行（实质无丢失）。

## 实验三 · 问答双臂（信息型问答）

**任务原文**：两问——①Agent Skills 规范中 SKILL.md frontmatter 的 name / description 长度限制 ②本仓库 VERSION 文件内容

| 组 | 条件 | 证据 | 结果 |
|----|------|------|------|
| **A 组 · 加载 skill** | skill v1.5.2 | 会话截图 | 双问全对（name 64 / description 1024，来源标注官方文档；VERSION=1.5.2 **实测读取**），57s，额外自检本机 skill 合规性 |
| **B 组 · 不加载 skill** | 裸平台 | 会话截图 | 双问全对（同样搜索核实 + 真读文件 + 来源标注），22s，平台记忆迭代对比 |

**结论（负结果）**：**双臂满分、无差异**——强平台默认行为已覆盖核实动作。裁决：**问答强制调研条款撤销**（与 P1-2b 呼应：默认行为良好时强制条款是纯成本）。skill 价值定位收窄清晰：**交付型任务的行为纪律，问答不掺和**。
