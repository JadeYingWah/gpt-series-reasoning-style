## 关键实验结果

### 菲比秋比复测（创作类，陌生专名「菲八秋比」）
- **带 skill（A 臂）**：两轮 WebSearch 定性「菲比啾比」（《鸣潮》团子梗）→ AskUserQuestion 三问确认（角色/规模/画风）→ 确认后才动手；交付含主角形象、图鉴、魔丸彩蛋、存档。
- **无 skill 对照**：任务核心词「菲比秋比」被**静默丢弃**——交付的通用钓鱼游戏里没有该角色、没有任何主题元素（截图在案，会话记录）。
- 验证条款：L13 陌生触发 ✓、L11 从零新建 A 档确认 ✓。

### 三游戏对照（批量任务，「要我能打开游玩的」）
- **带 skill（A 臂）**：A 档明确问过用户（环境/启动方式）→ 交付 **exe 双击直启**（jpackage 自带 JRE + PyInstaller 打包环境）——3/3 可玩 ✓；逻辑层无头测试全绿；顺手修复 ConcurrentModificationException 崩溃；第二轮将首轮未验证项全部自动化闭环。
- **无 skill（B 臂）**：bat 启动的两个游戏（PVZ / 保卫萝卜）在**用户环境无法启动**（依赖 py 启动器与 JDK PATH）——「能打开游玩」2/3 未达成；自测通过发生在被测自己的环境。
- 验证条款：L11 从零新建 A 档确认 ✓（问一句换来 exe 化正确决策）；「验证环境必须是用户环境，或把环境依赖消灭在交付里」实证。

### 问答双臂（信息型问答，另有会话记录）
- 双臂满分、无差异：强平台（深度思考 + 搜索 + 读文件）默认行为已覆盖核实动作。
- 裁决：问答强制调研条款（qa-rules）**撤销**——不为默认行为良好的场景加条款（与 P1-2b 呼应）。
