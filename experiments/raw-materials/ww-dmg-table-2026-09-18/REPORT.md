## 4. 创意上限讨论（设计边界，非缺陷清单）

| 对象 | 是否被 skill 压 |
|---|---|
| 本任务（验算器） | **几乎不压**——上限在正确性；变异/交叉验证反而抬高正确性 |
| 构想 / 脑暴 | **不压**——门禁刻意推迟读纪律；阶段1 禁读 rules |
| 确认前方向讨论 | **不压**——A 档是对齐范围 |
| 开工后换道 | **有摩擦**——改方向须回 A 档 |
| 开工后无限精修 | **有硬顶**——≤2 轮 / 单最弱项；超了回选项卡 |
