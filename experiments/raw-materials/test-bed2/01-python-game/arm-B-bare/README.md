# 暗影地穴 · Shadow Crypt

一个纯 Python 标准库实现的终端 Roguelike 地下城探险游戏，无任何第三方依赖。

## 运行

```bash
python main.py        # 需要 Python 3.10+
python selftest.py    # 运行 19 项自动化自检
```

## 功能一览

| 需求 | 实现 |
| --- | --- |
| 随机生成地图 | 房间 + 走廊算法，每层随机布局，房间过少自动重试 |
| 回合制战斗 | 玩家行动一次 → 全部敌人行动一次；伤害 = 攻击 − 防御 ± 随机浮动，10% 暴击翻倍 |
| 道具装备掉落 | 敌人按层权重掉落武器/护甲/药水/金币；魔王掉落专属神器 |
| 角色属性成长 | 击杀获得经验，升级提升生命/攻击/防御；力量药剂永久加攻 |
| 存档读档 | JSON 全量序列化（含 RNG 状态与战争迷雾），下楼自动存档，主菜单可继续冒险 |
| 敌人 AI | 睡眠 → 发现（视距 + 视线）→ BFS 寻路追击 → 相邻攻击；未被惊扰时随机徘徊 |
| 至少 3 层地下城 | 共 3 层，敌人逐层增强，第 3 层有蓄力重击的魔王 Boss |

额外系统：Bresenham 视线视野与战争迷雾（探索区域记忆显示）、背包换装、金币自动拾取。

## 操作

| 按键 | 功能 |
| --- | --- |
| W / A / S / D | 上 / 左 / 下 / 右移动（撞上敌人即为攻击） |
| `.` 或空格 | 原地等待一回合 |
| g | 拾取脚下道具 |
| e 或 `>` | 站在楼梯上时下行 |
| i | 打开背包（序号使用 / 装备） |
| S（大写） | 存档 |
| ? | 帮助 |
| Q | 退出（可选保存） |

注意大小写：小写 `s` 是向下移动，大写 `S` 才是存档。

## 目标

深入 3 层地下城，击败第 3 层的**暗影魔王**即获胜；生命归零则失败。
魔王每第 3 次攻击必定蓄力重击，注意用楼梯层间的成长与装备压制它。

## 代码结构

```
main.py              程序入口、主菜单与主循环
selftest.py          19 项自动化自检
roguelike/
  config.py          全局配置与数值表
  mapgen.py          房间+走廊随机地图生成
  fov.py             Bresenham 视线与视野
  items.py           道具定义与按层掉落表
  entities.py        玩家/敌人实体与成长
  combat.py          回合制战斗结算
  ai.py              敌人 AI（睡眠/徘徊/追击/攻击）与 BFS 寻路
  engine.py          游戏状态、楼层构建、回合引擎
  save.py            JSON 存读档（含 RNG 状态）
  render.py          终端渲染
```
