# 地下城探险（Roguelike Dungeon Crawler）

纯 Python 标准库实现的终端 Roguelike 游戏，零第三方依赖，Windows / Linux 可运行。

## 运行

```bash
python main.py                # 新游戏（有存档时询问是否继续）
python main.py --seed 42      # 固定随机种子（复现地图）
python main.py --load         # 从存档继续
python main.py --demo 500     # 无头自动演示 500 回合（不进交互界面）
python tests/smoke_test.py    # 冒烟测试（15 项断言）
```

需要 Python 3.10+。Windows 终端（Windows Terminal / PowerShell / cmd）直接运行即可。

## 按键

| 按键 | 功能 |
|---|---|
| `w a s d` / `h j k l` / 方向键 | 移动 / 撞向怪物即攻击 |
| `.` | 原地等待一回合 |
| `g` | 拾取脚下物品 |
| `i` | 打开背包（数字使用/装备，`d数字` 丢弃） |
| `>` | 站在楼梯上时进入下一层 |
| `S`（大写） | 存档 |
| `q` | 保存并退出 |

## 游戏内容

- **5 层随机地下城**：房间 + 走廊算法生成，BFS 保证楼梯必然可达；第 5 层无楼梯，击败「远古魔龙」即胜利
- **回合制战斗**：伤害 = 攻击 + 随机浮动 − 防御（保底 1），10% 暴击双倍
- **敌人 AI**：视野内 BFS 追击、丢失目标后走向最后目击点再转入游荡；洞穴蝙蝠一回合行动两次；怪物属性随楼层深度 ×(1+0.35·层号) 缩放
- **道具与装备**：治疗/大力/铁皮药水、火焰/治疗卷轴、匕首→战斧、皮甲→板金甲；武器护甲各一装备槽，换装自动卸下旧装备
- **角色成长**：经验升级，每次升级 HP 上限 +6、攻 +1，每 2 级防 +1，升级回满血
- **存档**：JSON 全状态序列化（含 RNG 状态、各层地图/怪物/物品/探索记忆），原子写入，坏档/版本不符自动拒收
- **视野**：半径 8 的遮挡视野 + 战争迷雾记忆

## 代码结构

```
main.py                  入口：交互主循环 / --demo / 键盘输入
roguelike/
  config.py              全部平衡数字（集中可调）
  map_gen.py             地图生成 + 连通性验证
  entities.py            实体 / Fighter / 背包
  items.py               道具定义与楼层加权掉落
  combat.py              伤害公式 / 暴击 / 升级
  ai.py                  敌人 AI（视线、BFS 寻路、状态机）
  fov.py                 视野与探索记忆
  save_load.py           存档文件 IO / RNG 状态序列化
  engine.py              游戏状态机、回合驱动、换层、序列化
  renderer.py            ANSI 终端渲染
tests/smoke_test.py      15 项无头冒烟测试
```

## 测试说明

`tests/smoke_test.py` 覆盖：地图连通性（100 seed × 5 层）、伤害公式边界、升级曲线、
AI 追击、物品装备与背包上限、存读档往返一致 + 坏档容错、Boss 层结构、换层位置回归、
2000 回合全流程、击杀 Boss 胜利判定、玩家死亡判定、RNG 序列化。
