# 弗糯糯炒饭双臂对照实验

**日期**：2026-09-18
**任务**：二次元写实手绘画风 HTML 节奏烹饪游戏——弗糯糯炒饭
**变量**：是否使用 gpt-series-reasoning-style skill

## 实验设计

| 臂 | 条件 | 结果 |
|---|---|---|
| A臂（with-skill） | 使用 gpt-series-reasoning-style v1.6.0 | 四轨节奏演奏（D/F/J/K），BPM 120，约40秒谱面，375px宽，变异测试通过，C1 可验收 |
| B臂（without-skill） | 不使用该 skill | 单轨翻炒（空格/点击），10步菜谱，星级结算，无验证脚本 |

## 关键差异

**有skill（A臂）**：
- 交付自带三件套：做了什么/怎么验的/哪些没验
- 有可复现的验证脚本（verify-game.cjs）和截图证据
- 明确标注未验证项（手感/立绘/音画延迟）
- 完成档位标 C1，产品档未拉满
- 谱面更完整（四轨+计分+连击）

**无skill（B臂）**：
- 交付只说"已用无头浏览器跑通"，无具体验证细节
- 无变异测试、无可复现命令
- 游戏更简单（单轨+10步）
- 无明确未验证标注

## 文件结构

- with-skill/：A臂完整产物（含验证脚本+截图证据）
- without-skill/：B臂完整产物

## 观察

- 有skill的臂交付更完整，验证证据更扎实
- 无skill的臂游戏更简单，可能是因为没有阶段2规划
- 两个臂都完成了核心玩法，但质量深度有差距
