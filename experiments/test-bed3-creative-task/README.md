# Test-Bed 3：创意任务双臂对照实验

## 任务描述
画奥特曼骑哥斯拉的动画，要求有动画效果。

## 实验设计
- **A臂（带skill）**：加载 gpt-series-reasoning-style v1.4.41
- **B臂（裸模型）**：不加载任何skill
- 两臂在空目录里从零开始，互不可见

## 产物对比

| | A臂（带skill） | B臂（裸模型） |
|---|---|---|
| 文件大小 | 33KB | 29KB |
| 质量校验方式 | 真开浏览器渲染，截两帧目检 | Python解析SVG结构 |

## 关键差异

### A臂做了什么
1. 真开浏览器渲染，截两帧目检
2. 抓到了**5处视觉问题**：
   - 举起拳头和头部重叠——看起来像头上有根角
   - 抓鳍的手握在鳍尖——像捏着尖
   - 奥特曼头冠鳍几乎看不见
   - 远侧腿大腿上角从身体轮廓戳出缺口
   - 腹甲太圆像一排蛋
3. 修复后复验两帧确认
4. 列了3条未验证：
   - Firefox/Safari兼容性
   - 长时间运行性能
   - 移动端小屏适配

### B臂做了什么
1. 只做了SVG结构校验（XML well-formed、标签配对）
2. 没有真打开浏览器看渲染效果
3. 没有"哪些没验"清单

## 结论

**这就是skill的核心价值——防假完成。**

B臂看起来做完了：
- 结构校验通过
- 画面描述写得很详细

但如果不真打开看——那5处视觉问题（拳头和头重叠、头冠看不见、腹甲太圆）就发现不了。

**A臂花了时间真打开看，抓到了5处问题——这就是skill的增量。**

## 核心发现

**"真打开看一眼"这条规则是真的有用。**

B臂做了结构校验，但没真打开看——视觉问题全漏了。
A臂真打开看了——抓到了5处问题。

这正好验证了skill的核心价值：**让交付物"真的能用"，而不是"看起来能用"。**
