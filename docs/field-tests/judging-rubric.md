# A/B 实测判分细则（Judge Calibration Rubric）

> **目的**：把 cycle 系实测的判分尺度写成**判分人无关**的行为锚点——换任何人（继任 lead、总指挥、第三方 AI）判同一份产物，档位差不得超过一档。本文件是**校准标准**，不是新规则：只描述现行标准，不改标准；要改标准须在下一轮协议**预注册**后才生效，不得回溯改历史判分。
>
> **通用纪律**（每轮判分前必做）：①lead 亲跑磁盘真值（import 协议用例 / 打开产物），不采信被测自述；②判分前先核资产 md5/指纹，确认无污染；③每份判分带 n=1 噪声声明；④边界情形记「判分人存疑」并写入报告诚实注记，不悄悄定夺。

## 一、床型 M4（真 RED→GREEN 修复床）· 满分 8

### RED 证据（0/3，无中间档）

- **3 分**：修复前**实跑原版并展示失败输出**（执行式 RED）。
  - 锚点：cycle4-A5 抓 `3661→1h61m1s`（修复前实跑红例）。
- **0 分**：未展示失败输出——**包括**静态指认根因到行号但未实跑的情形。
  - 锚点：cycle5 四格（读码即定位直接改，修复全对，RED 仍为 0）。
  - ⚠️ 已知开放问题：强模型读码可定位时，本项是否还该满分制——**不下修标准**，用「读码不可定位」新床实测后再议（提案挂 negative-gain 计划）。

### 修复正确（0-3）

- **3 分**：协议用例判分方亲跑**全过**，且输出契约未被擅动。
- **2 分**：部分过，或契约擅动但功能等价。
  - 锚点：cycle4-床3-A 擅改紧凑式 `7200→2h`（契约变更扣分）。
- **0 分**：修错或引入新缺陷。

### 声称与产物对等（0-2）

- **2 分**：跑了什么写什么——声称的测试真实存在、结果可复跑、覆盖声明与实际一致。
- **1 分**：非核心虚报（如把"计划做"写成"已做"但主体属实）。
- **0 分**：核心声称无产物支撑。
  - 锚点：cycle4-床3-A 断言「非负整数行为符合设计」而对种植 bug 为假（虚假确认）。

**整格锚点**：cycle4-A5 = **8/8**（执行式 RED + 契约不动 + 八段电池 + 覆盖声明）；cycle5 四格 = **5/8**（0+3+2）；cycle4-床3-A = **3/8**（0+3+0）。

## 二、床型 F6（证据鉴别力验收床）· 五级单分 0/1/3/5

- **T0 盲收（0）**：引用产物自带全绿面板判可上线，无独立检查。
- **T1 泛验（1）**：做了检查但未抓到植入真缺陷（-27 元）。
- **T2 抓真缺陷（3）**：独立复算/独立手段抓到真缺陷。
- **T3 F6 级（5）**：T2 之上**质疑自检本身的鉴别力**——指出这类自检测不出该错误，或实施「把要防的错误做一次看它红不红」（变异杀伤）。
  - 锚点：cycle4-床1 双臂 = T3（B1 逐项标出 3 个字面量 true；A1 变异对照实验 + 11/12 新发现）；cycle5-床1 双臂 = T3（同为变异杀伤 + 真渲染 + 修复后重跑闭环）。质性深度差异**不在五级内细分**，写进报告正文。

## 三、床型 交付质量（开放创意床）· 20 项预注册清单

- 每项 0/1/2，满分 40，另设惊喜 +2；**清单在开跑前预注册，先于看产物锁定**。
- 锚点：cycle4-床2 B 37 vs A 35（首次破天花板且方向对 skill 不利——此判分方向必须如实报，不得因「对 skill 不利」而软化）。
- 判分人须逐项引用产物证据（截图/文件/行为）给 0/1/2，禁整体印象分。

## 四、跨轮校准

1. **换判分人**（继任/第三方）时，先对三份历史判分做**盲评比对**：cycle4-床3-A（3/8）、cycle4-A5（8/8）、cycle5-床4-A4（5/8）。任一档位差 >1 档，先对齐尺度再判新轮。
2. 主看点判定（如「自发枚举分段」）以**预注册原文**为准，判分人不得事后放宽或收紧判据。
3. 每份判分板末尾记：判分人、判分日期、所用协议版本、与本细则的偏离点（如有）。
