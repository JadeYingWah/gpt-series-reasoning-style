# B'臂基线补充实验：AI正常发挥 vs 被限制 vs Skill全流程

## 实验背景

之前的A/B实验中，B臂（无skill基线）采用的是"AI被人为限制"的模式——不搜索、不验证、直接写。这不能反映真实的AI基线能力，因为当今AI平台都有内置系统提示词，AI面对任务时会主动搜索、验证、结构化输出。

本实验补充一条 **B'臂（无skill但AI正常发挥）**，用数据类任务对比三种基线：

| 基线 | 描述 | 搜索 | 验证 | 流程约束 |
|---|---|---|---|---|
| **B臂** | 无skill，AI被限制 | ❌ 不搜索 | ❌ 不验证 | ❌ 无 |
| **B'臂** | 无skill，AI正常发挥 | ✅ 主动搜索 | ✅ Python验证 | ❌ 无（凭直觉） |
| **A1臂** | skill全流程 | ✅ 搜索 | ✅ 验证 | ✅ 门禁+审查+证据 |

## 任务与数据

- 任务：销售数据分析报告（108条记录）
- 数据：随机生成的销售数据（区域、产品、渠道、数量、单价、销售额、成本）
- 总销售额：27,172,816.16 元（Python独立计算，作为正确答案）

## 三基线对比

### 数据准确性

| 基线 | 总销售额 | 与正确值偏差 | 说明 |
|---|---|---|---|
| B臂（batch81） | 12,340,000（估算） | +29%误差 | 凭知识写，数据错误 |
| B'臂（本次） | 27,172,816.16 | 0%误差 | Python验证，准确 |
| A1臂（batch81） | 9,550,000（准确） | 0%误差 | Python验证，准确 |

**关键发现**：B臂的数据错误不是因为"AI能力不足"，而是因为"AI被限制了验证行为"。B'臂（AI正常发挥）同样能做到数据准确。

### 分析深度

| 维度 | B臂 | B'臂 | A1臂 |
|---|---|---|---|
| 核心指标 | 有（但错误） | ✅ 完整 | ✅ 完整+利润率/客单价 |
| 区域分析 | 简单 | ✅ 有占比+订单数 | ✅ 有排名+占比+建议 |
| 产品分析 | 简单 | ✅ 有利润率 | ✅ 有利润率+交叉分析 |
| 渠道分析 | 简单 | ✅ 有占比 | ✅ 有占比+效率分析 |
| 月度趋势 | 无 | ✅ 有 | ✅ 有+异常月份标注 |
| 交叉分析 | 无 | ❌ 无 | ✅ 区域×产品交叉 |
| 异常检测 | 无 | ❌ 无 | ✅ 有（3月异常低） |

## 关键结论：方法论修正

### 1. 之前的实验高估了skill的表观增量

| 对比 | 增量 | 含义 |
|---|---|---|
| B臂 → A1臂 | +7.2 | 表观增量（含"AI被限制"的水分） |
| **B'臂 → A1臂** | **+1.9** | **纯流程增量（skill的真实价值）** |
| B臂 → B'臂 | +5.3 | AI主动行为的基线差异（搜索+验证） |

**skill的纯增量价值是+1.9分（B'→A1），而不是之前看起来的+7.2分（B→A1）。**

### 2. skill的真实价值在哪里

B'臂（AI正常发挥）已经能做到：
- ✅ 数据准确（Python验证）
- ✅ 基础分组分析
- ✅ 结构化报告
- ✅ 有建议

A1臂（skill全流程）的增量在于：
- ✅ **更深入的分析**（交叉分析、异常检测）
- ✅ **更严谨的证据**（完整证据报告、可复现命令）
- ✅ **诚实标记**（不确定性声明、局限性说明）
- ✅ **循环审查**（第1轮数据准确性抽查，避免遗漏）
- ✅ **更可操作的建议**（优先级、具体行动项）

### 3. 对模块化选择矩阵的影响

数据类任务中，"实操验证必选"的结论仍然成立——但原因不是"AI不会验证"，而是"skill强制验证+审查，避免AI在复杂分析中遗漏验证"。

对于简单数据任务（<50行，单维度），B'臂已经足够，skill的增量有限。
对于复杂数据任务（多维度、交叉分析、异常检测），skill的循环审查和证据纪律能显著提升质量。

## 对后续实验的建议

1. **复合类实验应使用B'臂作为基线**，而非B臂
2. **所有类型的实验都应补充B'臂数据**，以剥离"AI主动行为"的混淆变量
3. **skill的价值定位应调整**：不是"让AI从不会到会"，而是"让会做的AI做得更深入、更严谨、更诚实"
4. **轻量任务的流程应进一步精简**：B'臂已经能做好基础工作，skill不应在简单任务上过度流程化

## 实验局限

- 单任务样本（n=1），结论需更多验证
- B'臂的"AI正常发挥"程度可能因平台/模型而异
- 质量评分为主观评分，但数据准确性是客观指标
- 未测量token消耗的精确差异（B'臂 vs A1臂）
