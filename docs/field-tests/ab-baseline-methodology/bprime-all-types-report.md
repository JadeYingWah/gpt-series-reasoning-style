## 实验目的

验证"AI正常发挥"（无skill但主动搜索+验证+结构化）作为真实基线，剥离"AI被限制"的混淆变量，量化skill的纯流程增量价值。

## 关键发现

### 1. B→B'的跳变是主要质量来源

| 对比 | 平均增量 | 含义 |
|---|---|---|
| B臂 → B'臂 | +3.3 | AI主动行为（搜索+验证）的基线差异 |
| B'臂 → A1臂 | +2.1 | skill流程约束的纯增量 |
| B臂 → A1臂 | +5.5 | 表观增量（含水分） |

**AI主动行为贡献了61%的质量提升，skill流程约束贡献了39%。**

### 2. skill纯增量按任务类型排序

| 排名 | 任务类型 | B'→A1增量 | 原因 |
|---|---|---|---|
| 1 | 建模类 | +2.8 | AI正常发挥容易遗漏自动化验证和完整OBJ |
| 2 | 冒险类 | +2.7 | 分支逻辑验证是AI容易遗漏的隐蔽缺陷 |
| 3 | 研究类 | +2.1 | 多源交叉验证和不确定性声明需要纪律 |
| 4 | 数据类 | +1.9 | AI会验证数据，但循环审查避免遗漏 |
| 5 | 视觉类 | +1.9 | AI知道WCAG但不会精确计算对比度 |
| 6 | 代码类 | +1.8 | AI本身会写基本测试，增量最小 |
| 7 | 创意类 | +1.6 | 创意类流程约束的增量价值最低 |

## 对skill定位的确认

**skill的核心价值不是"让AI从不会到会"，而是"让会做的AI做得更深入、更严谨、更诚实"。**

具体体现：
1. **验证深度**：AI会做基本验证，但skill强制自动化、可复现的验证
2. **审查纪律**：AI容易自我满足，skill的2轮循环审查逼出遗漏
3. **诚实标记**：AI倾向于过度自信，skill的UNVERIFIED机制保持诚实
4. **证据闭环**：AI会给结论，skill要求附可复现的验证命令
5. **任务自适应**：AI用通用方法，skill按任务类型调整验证重点

## 对模块化选择矩阵的影响

1. **轻量任务**：B'臂已经能做好基础工作，skill应进一步精简流程
2. **复杂任务**：skill的循环审查和证据纪律能显著提升质量
3. **验证密集型**（建模/冒险/数据）：skill增量最大，应强制全流程
4. **创意类**：skill增量最小，可考虑更轻量的配置

## 实验局限

- 单任务样本（n=1/类型），结论需更多验证
- 质量评分为主观评分，但验证结果是客观指标
- B'臂的"AI正常发挥"程度可能因平台/模型而异
- 未测量token消耗的精确差异
- 评分者偏差：同一AI评分可能存在一致性问题
