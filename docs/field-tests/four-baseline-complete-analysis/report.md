## 二、核心发现

### 发现1：B' > A2 — AI正常发挥 优于 skill精简流程

**5/7的单类型任务中，B'（AI正常发挥）分数高于A2（skill精简流程）：**

| 任务类型 | B' | A2 | 差值 | 显著程度 |
|---|---|---|---|---|
| 数据类 | 7.5 | 5.2 | +2.3 | 极显著 |
| 视觉类 | 6.5 | 5.5 | +1.0 | 显著 |
| 研究类 | 6.5 | 5.8 | +0.7 | 中等 |
| 代码类 | 7.0 | 6.3 | +0.7 | 中等 |
| 创意类 | 7.0 | 6.8 | +0.2 | 微弱 |
| 建模类 | 6.0 | 6.2 | -0.2 | A2微弱领先 |
| 冒险类 | 6.0 | 6.2 | -0.2 | A2微弱领先 |

**原因分析**：

A2臂的"精简流程"只加了形式化步骤（结构化输出模板、基本搜索要求），但没有真正的验证深度。而B'臂（AI正常发挥）会：
- 主动搜索相关最佳实践（1次搜索）
- 主动用Python/代码验证数据和功能
- 主动结构化输出（基于搜索到的最佳实践）
- 主动做基本的质量检查

这些**实质性动作**比**形式化流程**更有价值。A2臂的问题在于：它告诉AI"要做什么步骤"，但没有强制AI"做到什么深度"。

### 发现2：四基线增量分解

| 对比 | 平均增量 | 含义 | 性质 |
|---|---|---|---|
| B → B' | +3.4 | AI主动行为（搜索+验证）的价值 | 能力释放 |
| B → A2 | +2.8 | skill精简流程的表观增量 | 形式化 |
| B' → A1 | +2.1 | skill全流程的纯增量 | 纪律约束 |
| A2 → A1 | +2.7 | 从精简到全流程的增量 | 深度验证 |

**关键洞察**：
- B→B'的增量（+3.4）是最大的，说明"让AI自由发挥"比"给AI一套精简流程"更有效
- A2的表观增量（B→A2，+2.8）有水分，因为B是被限制的基线
- 用真实基线B'衡量，A2甚至是负增益（B'→A2 = -0.6）
- A1的纯增量（B'→A1，+2.1）是真实的、稳定的

### 发现3：A1臂的稳定优势

A1臂在所有8类任务中都是最高分，且优势稳定：

| 指标 | 数值 |
|---|---|
| 最低增量（vs B'） | 创意类 +1.6 |
| 最高增量（vs B'） | 建模类 +2.8 |
| 平均增量（vs B'） | +2.1 |
| 增量标准差 | 0.41 |
| 增量变异系数 | 19.5% |

**A1的核心价值**（AI正常发挥不会系统性执行的纪律）：
1. **循环审查**（2轮）：逼出AI自我满足时遗漏的问题
2. **多维度验证**：数据+视觉+代码+功能，跨维度一致性检查
3. **证据闭环**：每个结论附可复现的验证命令
4. **诚实标记**：UNVERIFIED机制，防止过度自信
5. **任务自适应**：按任务类型调整验证重点

## 三、对skill的改进建议

### 建议1：重做A2精简配置

**问题**：当前A2配置只是"减流程"，没有"保验证"，导致效果不如B'。

**改进方向**：
- A2不应是"A1的简化版"，而应是"验证聚焦版"
- 保留最核心的验证要求（数据准确性、功能测试、基本审查）
- 去掉形式化步骤（14字段门禁可减为5字段、循环审查可减为1轮）
- 明确告诉AI："精简不等于省略验证，而是聚焦最关键的验证"

**预期效果**：A2分数应从6.0提升到7.0+（至少不低于B'）

### 建议2：模块化选择矩阵增加B'参照

在矩阵中增加一列"AI正常发挥基线（B'）"，让AI知道：
- 这个任务类型，AI正常发挥能做到什么水平
- skill的增量具体在哪里
- 什么情况下可以跳过skill（简单任务，B'已经足够）

### 建议3：轻量任务的智能降级

对于简单任务（如单文件修改、简单问答），skill应支持：
- 自动检测任务复杂度
- 简单任务自动降级为"验证聚焦"模式（A2改进版）
- 只保留1轮审查+关键验证，不做全流程
- 避免过度流程化拖累效率

### 建议4：验证密集型任务强制全流程

对于建模、冒险、复合类，A1增量最大（+2.6~+2.8），应：
- 在模块化选择矩阵中标注"建议全流程"
- 即使是轻量配置，也必须包含该类型的核心验证工具
- 例如：建模类必须有OBJ验证脚本，冒险类必须有分支逻辑验证

## 四、实验局限

1. **单任务样本**（n=1/类型），结论需更多任务验证
2. **主观评分**：质量评分为同一AI评分，可能存在评分者偏差
3. **A2配置未优化**：当前A2是初始版本，改进后可能分数提升
4. **复合类A2未测**：复合类只有B/B'/A1三臂数据
5. **token消耗为估算**：未精确测量各臂的token消耗
6. **平台依赖性**：B'臂的"AI正常发挥"程度可能因平台/模型而异

---

## 五、结论

1. **AI主动行为是质量的主要来源**（B→B' +3.4分，占总增量的62%）
2. **skill全流程有真实、稳定的增量**（B'→A1 +2.1分，占38%）
3. **skill精简流程（A2）当前版本有问题**：效果不如AI正常发挥，需要重做
4. **skill价值与验证需求正相关**：越需要自动化验证的任务，skill价值越大
5. **skill的核心竞争力是"验证纪律"**：循环审查、多维度验证、证据闭环，这些是AI正常发挥时不会系统性执行的

**一句话总结**：skill不是让AI"从不会到会"，而是让"会做的AI做得更严谨、更深入、更诚实"。当前的精简配置（A2）需要重新设计，全流程配置（A1）的价值已被8类任务验证。
