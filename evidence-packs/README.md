# 证据包索引 · Evidence Packs

> **本目录是 skill 的活数据资产**：每份包 = 一类任务的**历史致命缺陷模式清单**，由实验判定台/真实交付上机械抓到的 fatal 蒸馏而来。
> **使用方式**：交付宣告后、做对抗复核时，按任务类型取对应包，逐条自查"我的实现遇到这类输入会怎样"。**执行期不需要读**。
> **每条模式四件套**：①模式描述（带来源）②双向致命声明 ③自查输入建议 ④检测思路一句话。

## 双向致命原则（防过度矫正，最重要的一条）

**漏报和误拒都是致命缺陷**：
- 漏报 = 静默接受非法输入并给出结果（历史上最常见）
- 误拒 = 拒绝合法输入（历史上在"加固"后反复出现——修 F1 时引入）

每条模式自查时，必须同时验证两个方向：非法输入被正确拒绝，**且合法输入不被误伤**。

## 增长机制

每次实验判定台或真实交付新抓到 fatal → 蒸馏一条进对应包（日期+来源哈希），修改后跑 selfcheck。本目录与 SKILL.md 行为条款的分工：**条款管动作，本目录管"该怀疑什么"**。

## 已知边界（诚实声明）

清单只覆盖**已发生过**的模式；没发生过的仍会漏（清单天花板）。缓解手段只有持续反哺，无法归零。
